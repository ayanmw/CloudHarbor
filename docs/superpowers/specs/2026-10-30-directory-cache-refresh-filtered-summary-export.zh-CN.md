# 刷新运行筛选摘要导出

## 目的

`.90` 支持按最新状态和启动 UTC 日期查询刷新运行，`.89` 支持导出单轮完整事件。此功能允许用户把当前筛选命中的运行摘要一次性保存为 JSON，便于离线盘点和比较。

## 范围

- 管理页新增“导出当前筛选摘要”按钮；显式点击后下载 JSON。
- 导出使用当前已提交的状态与 UTC 日期筛选，包含筛选值、导出时本机 UTC、摘要行和总数。
- Store 在单个 SQLite 只读事务中读取有序结果，最多 5,000 条；超过上限整份拒绝，不导出部分结果。
- 账号只从认证上下文取得；账号指纹不出现在 JSON。筛选改变后，旧导出响应不得下载。
- 摘要列只复用现有运行 DTO，不包含逐事件 evidence。

## 不做

- 不导出事件、扫描缓存或百度网盘数据。
- 不新增 schema、筛选条件或后台任务。
- 不访问百度网盘、不改变刷新状态。

## 验收

- Store 覆盖筛选复用、排序、同快照查询、5,000/5,001 边界、超限整份拒绝、账号隔离、关闭/取消错误。
- Downloader/API 覆盖认证账号、参数校验、文件名、过滤条件回显、`no-store`、超限与失败路径；未授权路由被拒绝。
- WebUI 覆盖只在点击时请求、当前筛选透传、文件下载、HTTP 错误提示和过期响应保护。
- 全仓 Go/vet、WebUI/userscript、Windows AMD64/Linux AMD64/Linux ARM64 构建、ZIP 和来源快照检查通过。
- 本地 SQLite/mock 验收，不访问真实百度账号或 NAS/SMB。
