## v0.8.30-preview.140：全盘扫描覆盖原因快照历史

### 目标

在 `.139` 已记录的覆盖状态、未完整目录数、缓存 generation 和本机 UTC 基础上，补齐扫描完成时 9 类覆盖原因计数。原因计数允许重叠；历史值属于扫描完成时 SQLite 缓存快照，后续缓存变化不得改写。旧运行没有原因凭据时保持 NULL，不从当前缓存推断过去。

### 范围

- SQLite schema v38 新增可空原因 JSON；v37→v38 原子迁移，不回填旧数据。
- 完成状态、原因快照和 completed 事件在现有事务中提交；历史列表和单轮证据导出读取同一持久值。
- UI 与当前实时覆盖原因分开展示历史原因；旧运行明确标为历史未记录。
- 公共 API 继续使用白名单 DTO，不暴露账号指纹。

### 验收

taskstore 需覆盖历史原因重启保持、缓存变化不改写、旧记录迁移 NULL、完成事件失败回滚；API 列表/导出包含原因且不泄露账号指纹；WebUI 展示原因与旧历史缺省。随后运行全仓 Go/vet、WebUI/userscript、Windows AMD64/Linux AMD64/Linux ARM64 构建及预览包完整性门禁。仅本机 SQLite/mock，不触发真实百度扫描或远端写操作。
