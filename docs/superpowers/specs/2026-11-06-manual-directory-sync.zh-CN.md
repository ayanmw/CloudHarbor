# 手动目录同步与真实网盘验收设计

当前固定v0.8.31；主目录内联实现，保留未提交工作，不提交/push/worktree。用户已授权真实账号独立目录测试，以及最佳推荐实施；2026-11-06确认单向为网盘→本地、首次合并不传播缺失删除、双端冲突保留。

## 交付顺序

1. 真实基础API矩阵：列举/空目录、创建、中文改名、跨目录移动、复制、删除（仅本次夹具）、上传、下载与摘要；缓存刷新前后和重开后的记录核对。
2. 缓存日志：保留原始逐目录事务证据，增加每轮新增/删除/改名/移动的关联视图。相同fs_id关联移动，不能根据同名或等大小猜测；不完整扫描不能证明删除。首次建档明确标记，后续每轮即使无变化也保留运行记录。
3. 手动目录同步：网页选择服务所在主机的绝对本地目录及网盘目录，模式为网盘→本地或双向。独立SQLite维护配置、双端快照、共同基线、运行批次、计划、逐项执行与时间证据。沿用现有下载客户端、上传和远端变更执行器，不绕开认证/互斥/未知隔离。

## 算法与数据边界

每轮：完整读取两端→与上次成功共同基线三方比较→持久计划→逐项前置核对与执行→两端重新扫描→确认收敛→事务提交新基线。运行失败、冲突或未知不能推进共同基线；已成功步骤保留凭据，下轮先核对，不能盲重发。每项在执行前保存intent，执行后保存结果与UTC，区分本地观察、线上观察、执行和本机记录时间。

首次合并：同路径同内容建立关联；仅远端有则下载，仅本地有时双向上传、单向保留；同路径不同内容保留双方并记冲突。之后一端变化而另一端与基线一致才传播；双端都改动且结果不同、改动对删除、目标被占用、类型冲突均停止该项目并记录冲突。单向不上传本地变化，也不静默覆盖本地偏离基线的内容。

移动/重命名优先使用稳定身份：远端fs_id，本地文件系统文件身份；身份不明确时不能宣称已识别移动。目录操作影响子树，计划消除父子重复操作，删除最后执行并要求空目录，不递归删除未经列举的内容。相同内容不是同一身份。大小与mtime不单独作为内容一致凭据，使用SHA256；远端MD5只是元数据，不直接当作本地MD5。缓存摘要带身份/大小/远端mtime/观察UTC，执行涉及覆盖/删除前重新核对。

本地文件发布采用同目录临时文件、内容校验、落盘后原子改名；原内容进入本地隔离区，避免直接覆盖造成不可恢复。拒绝符号链接/reparse、目录逃逸、大小写碰撞、同步目录与账号状态/现有下载目录重叠、重叠同步配置。根目录消失或分页失败作为扫描失败，不解释为整树删除。

跨重启：running恢复为中断待核对；intent无完成凭据保持unknown，不能自动重发远端写入。配置不可在运行中修改；每次手动开始显示范围、方向、上次基线、差异/冲突。无差异也记录完整运行结论。网页以表格显示批次和逐项来源/目标、动作、前后身份/摘要、状态、时间、错误，可导出JSON。

## 本轮实施裁决与边界

- 单向模式已共同建档的本地项目自行变化时，明确记录冲突，不把偏离内容吸收到共同基线；即使本轮远端未变，也保留旧基线，避免未来远端变化覆盖本地修改。首次本地独有项目继续保留、不上传。
- 目录移动展开为目标目录建立、稳定文件身份移动和旧空目录清理，逐项记录，不递归删除。目录自身身份可能变化，大目录改名请求数会较多；整目录原子移动优化留待单独验证，不伪装为一次供应商原子操作。
- 远端内容覆盖先把旧对象移入所选远端根内的`.nas-sync-history/<配置ID>/<运行ID>`，再上传并下载校验新对象。本地覆盖/删除保留同名本地隔离区备份，校验SHA并同步目录链。隔离区只接受当前配置所有权；不自动清理。
- 配置绑定账号缓存作用域、应用指纹、远端根fs_id及本地文件系统根身份。当前路径设置在每次准入重新核对；根消失、链接、大小写碰撞或重叠均拒绝。
- 大小和mtime以十进制字符串写入新记录，明确本地Unix纳秒/远端Unix秒。兼容读取本轮早期候选数字记录，不把历史记录重新解释为新操作。
- 结果可明确证明未开始时记failed；已经尝试命名空间变更或复合覆盖已有部分副作用时记unknown并阻止重发。网页不提供强行解除未知的入口。
- 普通时间线只读取最近200条，双端完整快照显示数量摘要；JSON导出保留全量快照/事件。批次使用游标查看更早记录。原始缓存变化最多10000条的派生汇总，超限转向原始逐目录分页，不返回半份汇总冒充完整。
- 文件身份核对与实际文件系统/API调用间仍有竞态；远端列表不是原子快照。以完成后的再次扫描、冲突、保留备份和明确未知记录处理，不承诺跨两端的分布式事务或断电/NAS耐久验收。

## 验证分层

纯算法/SQLite故障注入用于验证冲突与回滚；真实账号矩阵证明供应商链路；独立本地/远端测试目录验证双向新增/改名/移动/删除、无变化重复运行、冲突及重开，不将mock当真实验收。NAS/SMB、其他客户端高频并发、崩溃断电仍单列限制。不能承诺跨本地文件系统和百度服务的分布式原子事务；以逐项证据、前置校验和未知隔离兑现可核查记录。
