# .152 下载记录跨重启可见性

状态：五项已实现并通过本地发布验证。沿用用户已授权的主目录内联实现，不创建 worktree；五项交付完成并验证后才打包新预览。

## 目标与五项交付

1. 根任务保存本次尝试的本地目标路径及 UTC 记录时间，重启后可查看；明确它是历史目标，不能证明当前文件存在。
2. 目录准备时分批保存文件清单和远端观察时间，完整清单原子发布；未完成枚举不得冒充完整目录。
3. 文件最终发布并同步后，或本地内容通过完整校验后，记录完成依据；重启中断的运行态不得继续显示下载中或误报完成。
4. 根任务从持久化清单恢复文件数、目录数、总字节与完成数；区分完整清单、枚举未完成和旧任务无记录。
5. 明细提供数据库分页、搜索及状态筛选，展示观察时间与本地完成依据；避免把全部历史文件装入运行任务内存。

## 已核对的现状

`queueJob` 以 JSON 投影保存于 SQLite，根任务事件单独追加。`prepareDirectoryTree` 与 `preparePendingFile` 只创建内存任务。`taskViewLocked` 恢复根任务时未恢复本地路径。`buildTaskWorkspace` 从内存遍历统计后分页。`complete.json` 在最终文件发布前写入，因此单独存在不能作为发布完成证据。

## 技术选择及边界

采用 SQLite 持久化清单和查询，沿用现有 Go / Vue。根目标快照可扩展已有 job JSON，无需为此升级 schema；大量明细使用独立表及有界批处理，不嵌入根 JSON。保留内存全量任务快照会继续扩大内存且缺乏数据库分页；从下载文件或凭据反推历史则缺少可靠时间及目录完整性，两者均不采用。

路径快照在有效根路径完成校验、开始本地处理前写入，与关键事件原子保存。每次尝试可更新最新目标，旧值由追加事件保留；未记录的旧任务保持空，不按当前配置反推。该快照仅用于展示，恢复下载仍走现有路径校验，不能以历史路径驱动文件写入。目录迁移不会改写历史快照。

清单按根任务与尝试区分，记录远端身份、路径、大小、观察时间及本地相对路径。完整准备结束后再切换当前完整清单；新枚举期间旧清单可作为历史展示。文件完成状态必须绑定相同身份和清单。数据库保存失败应停止该任务进入网盘后处理；已发布文件可在下次经现有内容验证后补记录，无需盲目重下或重发远端写操作。

清单使用 schema v42 的独立表，每批最多 512 条，每页查询最多 200 条。条目 `observation_source` 区分 `root_task_snapshot`（接收现有根任务快照时记录，不能证明本轮重新在线核对）和 `directory_listing`（本轮目录列表 API 的返回记录时间）；`provider_mtime` 单独保存，不能用作本地完成时间。清单发布事务同时封存清单并更新当前指针；根条目或父目录关系不完整时拒绝发布。

文件结果使用同版 schema v42 的 `download_manifest_results`，复合外键绑定清单条目，记录 `published` / `local_verified`、本地 SHA256 和本次观察 UTC，追加后不允许更新或删除。相同摘要的重复验证保留首次记录；摘要冲突拒绝。工作线程通过 context 绑定固定清单 ID，避免从随后变化的当前指针误取其他尝试。路径身份比较只将新历史键规范为 slash，不修改原有完成凭据格式。

`download_manifest_totals` 在清单发布事务内一次性聚合文件/目录数及容量，文件结果插入触发器在同事务更新完成数和完成字节。查询按主键读取该投影，避免轮询遍历全部文件。工作区在本次尝试 ID 和根身份匹配时恢复总数；不匹配的清单明确标为上一轮或原身份历史，不计入本轮。汇总读取错误返回 503，不能伪装成空目录；完成证据不代表重新核实当前磁盘或网盘状态。

不回填旧任务未记录的完成时间，不把远端修改时间当本地完成时间。不改变未知远端结果隔离规则，不主动操作真实百度账号或迁移唯一授权目录。

## 验收

使用临时 SQLite 关闭重开验证路径、清单、汇总、筛选及时间证据；注入保存失败验证不发布半份清单、不触发后处理；本地模拟下载验证发布前后边界。旧数据兼容、身份变化、重复尝试和大清单分页均须覆盖。最终执行 Go 测试、vet、前端测试及打包检查，真实百度/NAS 验收单列。

## 文件明细落地

`download_manifest_states` 保存未完成文件的本进程执行观察，开始/失败/取消写入固定安全分类及 run_id、UTC；成功结果事务清除该投影。重启或根任务停止后旧 downloading 查询为 pending/interrupted，不推定恢复或完成。SQL 执行状态排序、最多 200 行分页和基于预先 Unicode 小写 search_path 的字面量路径搜索；工作区只复制根和活动文件，当前页进度按本次身份叠加。

本地发布验证、独立审查及桌面/窄屏模拟验收通过；真实百度/NAS/SMB 与独立打包程序启动仍未验证。最终源码快照和包哈希见发布目录同级 .152-validation.md。
