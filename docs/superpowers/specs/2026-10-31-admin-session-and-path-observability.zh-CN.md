# 管理登录与路径操作可观测性设计

## 目标

把管理登录和本地路径维护中已核实的五个问题合并为一个可验收批次：路径输入保真、登录失败限流可恢复、登录失效提示友好、状态读取错误不伪装成无历史、迁移轮询避免请求重叠。

## 当前实现与问题证据

1. `internal/webui/index_cloud.html` 提交路径时对队列路径和本地路径调用 `.trim()`。队列路径校验允许云端名称含空格，因此 `/monitor ` 会在提交前变成 `/monitor`，改变了用户指定对象；服务端 `SetManagedPaths` 原样接受该云端路径。现有入队和云端目录输入已专门保留有意义的首尾空格。本地下载路径仍按现有规范化规则处理，不纳入此项。
2. `internal/management/auth.go` 的失败计数按来源地址保存在内存 map 中。只有该地址再次尝试时才清理自己的过期条目；达到 1024 个地址后，新的来源一律被拒绝。若旧来源不再回来，过期项永不被清除，可造成持续登录拒绝。
3. 云端管理页本地 `api()` 直接将 401 响应正文作为错误消息展示；认证中间件返回英文 `administrator authentication required`，没有提示重新登录。
4. `scanStatus` 和 `directoryRefreshStatus` 在任何请求错误时都把摘要写成“尚无…记录”，把服务不可达/登录过期与确实没有历史混为一谈。
5. `pollMigration` 使用 `setInterval` 每 1.5 秒调用自身。若一次状态读取超过间隔，后续轮询会并发启动，迟到的旧状态可能覆盖新状态并产生多余请求。

## 设计

- 网盘监控目录沿用现有输入保真语义：网页发送其原始值，不去除非空输入的首尾空格；禁止队列路径格式校验因这项改动变宽。本地下载路径继续使用当前规范化规则。
- 登录尝试准入时先删除所有超过 15 分钟窗口的失败记录，再应用既有每地址 10 次和 map 容量上限；不读取未验证的代理转发头，不改变地址信任边界。
- 云端管理页对 401 显示统一中文“管理员登录已失效，请重新登录”提示；下载类请求保留其现有错误呈现方式，只统一认证提示，不自动重放任何请求。
- 扫描状态读取失败时保留“读取失败”语义并展示错误；只有服务端明确返回 `none`/空状态时才显示“尚无记录”。不清除最后一次成功读取的任务证据。
- 迁移状态最多允许一个在途请求。请求完成后由现有 1.5 秒轮询继续；正在进行的请求不会被重复发起，已终态后停止计时器的行为保持不变。

## 不在本批范围

- 不改变管理员会话的无限期限和显式登出规则。
- 不从 `X-Forwarded-For` 或 `Forwarded` 推断来源 IP；新增可信代理配置需要独立设计。
- 不改变本地迁移步骤、文件复制/删除行为或任何百度网盘远端操作。
- 不增加新配置项，不创建独立版本号直到五项均完成并通过发布门禁。

## 验收

五个独立行为分别以 RED/GREEN 回归确认；随后通过 downloader、management、intakeapi Go 套件、全仓 Go 测试与 vet、Web UI/userscript 套件、三平台打包和 ZIP 敏感运行数据检查。真实百度/NAS 只在有对应授权与环境时另行验收。
