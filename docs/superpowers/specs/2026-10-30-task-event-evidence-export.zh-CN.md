# 下载任务事件证据导出

## 目标

管理员可以从单个下载任务的事件时间线下载一份完整、脱敏、可用于故障排查的 JSON 证据文件。

## 范围与行为

- 在任务事件时间线中增加“导出事件证据”按钮；仅在用户主动点击时请求导出。
- `GET /api/tasks/{id}/events/export` 受现有管理员会话保护，只读取本地任务 SQLite，不访问百度网盘、不修改任务或事件。
- 在单个 SQLite 只读事务快照中验证任务存在并读取事件；按 sequence 升序返回。
- 最多导出 100 条事件；超过上限整份拒绝（HTTP 413），不得返回部分证据。
- JSON 包含导出 UTC 时间、任务 ID、事件总数和完整事件列表；所有嵌套证据字段名包含 token、secret、password、authorization、appkey 或 signkey（大小写和 `_`/`-` 不敏感）时替换为 `[REDACTED]`。
- 响应设置 `Cache-Control: no-store` 和安全附件文件名。页面显示认证失效、超过上限、任务不存在和通用读取错误，不渲染服务端原始错误。

## 不在范围

- 不导出任务当前投影、下载文件或账号凭据。
- 不提供多任务/全队列批量导出、过滤器或远端操作入口。
- 不自动导出、不触发扫描、重试、取消、移动、删除或下载。

## 验收

- Store 回归：空事件、1/100/101 边界、升序、一致只读快照、无此任务和数据库错误。
- API 回归：认证、GET 限制、任务 ID 校验、404、413 全量拒绝、附件与 no-store 响应、递归脱敏、服务端异常不泄漏。
- WebUI 回归：用户点击才请求、成功下载、401/413/其他错误提示、避免重复点击。
- 全量发布门禁：`go test ./... -count=1`、`go vet ./...`、WebUI/userscript、Windows AMD64/Linux AMD64/Linux ARM64 构建、ZIP 校验与包内版本检查。

## 验收边界

本功能导出本地审计数据；本地模拟和浏览器 UI 测试不代表百度/NAS 下载链路验收。证据中可能包含任务路径和网盘文件名，下载文件由管理员自行保管。
