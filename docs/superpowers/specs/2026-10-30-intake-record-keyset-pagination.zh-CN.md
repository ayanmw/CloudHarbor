# 手动入队记录稳定分页

## 意图

手动入队页面的记录列表按创建时间倒序显示。当前使用 offset 分页；新预检或状态更新可能改变前页记录数量，使用户翻页时重复看到或漏看记录。此改进让下一页从上一页最后一条记录之后继续读取。

## 目标

- 固定记录排序为 `created` 降序、`id` 降序，保证同一时间戳下顺序稳定。
- 新增基于 `(created,id)` 的 keyset 游标；第一页之后按游标继续读取，不受列表头部新记录插入影响。
- 保留当前 offset 查询兼容性；网页切换为 keyset 游标。
- 网页维护本次浏览的游标栈，支持上一页；刷新记录或改变“只看待核对”筛选时回到第一页。
- 继续返回实时总数；过滤条件下记录状态变化导致记录移出结果集时，后续请求按当前状态读取，不承诺跨请求数据库快照。

## 非目标

- 不新增 SQLite schema，也不改变入队记录的持久化、保留期限或状态语义。
- 不增加删除、重发、移动等入队操作入口。
- 不把 offset API 从兼容层移除。

## 验收标准

- 在第 1 页和第 2 页之间插入更新的记录后，按游标取第 2 页仍从原第 1 页最后一条之后开始，不重复、不漏掉未变化的旧记录。
- 相同 `created` 时间的记录按 ID 稳定排序；非法、未知 ID 或格式错误的游标返回 400。
- `unresolved` 筛选与游标组合工作；筛选变更回到第一页。
- WebUI 上一页使用本次访问栈，下一页请求带 `before` 游标；新记录不导致浏览器页面错位。
- 全仓 Go 测试、vet、WebUI/userscript 与三平台包门禁通过；此单项不单独创建 preview。
