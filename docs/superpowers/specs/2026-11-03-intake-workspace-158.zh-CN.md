# .158 添加网盘项目工作台

采用用户已授权的最佳推荐方案：将/intake旧HTML与脚本迁移到现有Vue工作台，共用导航、紧凑表格和抽屉。不修改远端移动业务、完成凭据、隔离或重发规则，不新增持久化。

本版五项可独立体验的改进：
1. 目录表格：名称、类型、大小独立列，目录隐藏0B；路径输入、面包屑/上一级、分页及始终可见的空目录容器，加载失败与空结果区分。
2. 跨目录已选清单：保留最多20项路径，逐项移除/清空，明确不可选提示，手工路径输入与勾选同步；修改输入立即使旧预检失效。
3. 预检与确认：固定源/目标/后处理策略/有效期紧凑对照，显式确认勾选及单次提交。提交期间禁改选择，过期/认证变化必须重新预检；断网或未知不能重发移动。
4. 入队历史：批次摘要表格、待核对过滤、原样opaque cursor分页、批次详情展示源/目标/逐项状态和原UTC时间。失败保留旧结果但不能混用新筛选游标。
5. 结果与重新核对：清楚区分未提交、未发送、已核对、失败及未知隔离；保留现有recheck能力且明确只核对、不重发。换批次/目录迟到隔离，401引导登录，窄屏与键盘可用。

接口沿用/api/cloud、/api/oauth/status、/api/intakes/preview、/api/intakes、/{id}/commit与/{id}/recheck，实际路径以现有路由核实。所有操作身份用已有string id/source_id，不能把JSON数字fs_id显示成精确身份。预检有效期按服务端返回值，后端仍最终校验，浏览器时钟仅提示。

只用原目录，不worktree/提交/push。测试使用本地模拟，不复制真实授权、不执行真实移动。扫描保持现有正常请求，遇明确限流再退避；本版不改变扫描调度。

验收：先失败再实现的行为回归、Go路由及权限测试、旧能力对照、最终独立审查、桌面/390px/焦点模拟验收、完整Go/vet/前端/旧页及三平台门禁，最后同版打包。真实百度/NAS验收另列，不以模拟替代。
