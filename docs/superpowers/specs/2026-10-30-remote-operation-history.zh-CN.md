# 远端操作历史只读视图设计

## 意图

让管理员在网盘管理页查看本地 SQLite 已保存的远端操作结果和追加事件，尤其是在页面刷新或程序重启后仍能核对操作时间线。`.58` 已持久化 `remote_operations` 与 `remote_operation_events`，但网页目前只在操作完成时短暂显示 operation ID。

本批按“继续推进路线图”的授权，采用上一轮建议的只读历史页作为默认方向；若用户之后明确选择其他方向，按新指示调整。目标是完整的一项用户可见功能，满足一个 preview 的版本门槛。

## 目标

- 网盘管理页以折叠区展示远端操作记录，支持按状态筛选、分页和查看单笔事件详情。
- 显示操作 ID、类型、最终状态、源/目标路径、对象 fs_id、发起时间、服务端响应观测时间，以及本地追加事件记录时间。
- 所有时间以 ISO-8601 UTC 返回，并在页面标明 UTC。
- 列表和详情只读 SQLite，不访问百度 API，也不改变队列、缓存或远端对象。
- 结果未知保持隔离；历史页不提供重发、确认、放行、删除日志或清理日志入口。
- 保持账户边界：下载目录已按百度 `uk` 绑定单一账号；同一账号的历史不按可轮换的 access-token 指纹过滤。API 不返回内部 account fingerprint。

## 非目标

- 不合并任务事件时间线；任务事件与远端操作事件含义、时间字段和分页边界不同。
- 不增加人工处理 `unknown` 的功能。
- 不更改 SQLite 事件记录、保留策略或远端操作执行流程；不修改 schema。
- 不对网盘内容执行核对、刷新或写操作。

## 方案比较

1. **只读列表和详情 API + 管理页折叠区（本批采用）**：复用现有 SQLite 操作投影和追加事件，职责清楚，可在重启后查阅；增加分页查询和一个只读页面入口。
2. **把远端操作并入任务事件列表**：界面更集中，但并非每笔网盘操作都对应下载任务，且两种事件时间线的筛选与分页不同，容易混淆。
3. **仅提供命令行或数据库查询**：实现较少，但用户无法从现有管理页面查看，达不到易用性目标。

## 设计

- 新增受现有管理认证保护的 GET 接口：操作列表按 `created_at_utc DESC, operation_id DESC` 排序，支持可选状态和有上限的分页；详情接口按 `sequence` 分页返回单笔操作的追加事件。
- 数据访问限定在当前下载目录绑定的 SQLite store。详情查询必须先验证 operation ID 属于该 store；不存在的 ID 返回 404。内部 account fingerprint 不返回浏览器。
- 事件包含状态、`recorded_at_utc`、可空 `response_observed_at_utc` 和证据 JSON。证据仅以 `textContent` 或等价转义方式呈现，避免 HTML 注入；字段名含 token、secret、password、authorization 的值在 API 返回前递归掩码。未知状态只显示警示说明，不出现任何变更按钮。
- 网页默认折叠历史区，列表每页 20 笔，可选择状态、上一页/下一页；单笔详情按需加载事件。读失败显示本地读取错误，不触发实时百度请求。
- `remote_operations` 当前记录量较小；本批不新增 schema/index。查询必须使用 SQL 参数，限制 `limit` 与 `offset`，避免无界读取。

## 验收标准

- Store 回归覆盖时间倒序、状态筛选、账户存储隔离、offset/limit 边界、事件序列分页、未知 operation ID，以及数据库关闭错误。
- API 回归覆盖 GET-only、过滤/分页输入校验、404、无百度调用，并确认不在响应中泄露 account fingerprint 或证据内敏感字段。
- WebUI 回归覆盖折叠区按需读取、状态筛选、分页、UTC 时间/unknown 文案、详情转义，以及没有重发/放行/删除操作的控件。
- 全仓 Go 测试、`go vet ./...`、WebUI/userscript 测试和 Windows/Linux AMD64/Linux ARM64 构建通过；更新 `.59` 测试包并核对 ZIP 清单/hash。
- 真实 `.58` 运行状态继续保持单份；新包不包含 `.nas-downloader`。发布后将唯一运行数据按用户授权移动到 `.59`，验证历史记录跨包启动仍可读。

## 实现者决定

- 状态枚举复用现有 `prepared`、`confirmed`、`unknown`、`failed`，前端提供“全部”作为不筛选选项。
- 列表上限 50，默认 20；详情事件默认 20、上限 50，按序列号倒序分页并在页面从旧到新展示。
- 不回显任何证据对象中被识别为敏感字段的值；其它审计字段按原值显示。
