# 本地目录迁移证据导出设计

## 目标

在“自动下载路径”页面增加导出最近一次本地目录迁移 JSON 的入口，便于排查迁移冲突、文件占用和中断恢复过程。

## 证据内容

- SQLite 同一个只读事务快照中的最新迁移摘要与追加事件。
- 摘要包含迁移 ID、源/目标路径、目标网盘队列路径、状态/阶段、文件数和字节数、开始/更新时间/完成时间及最后错误。
- 事件按序号升序导出，包含本机记录 UTC 时间、状态/阶段和已有证据 JSON。
- 最多导出 100 个事件；超过上限则拒绝整份导出，不截断以免误认为证据完整。
- 没有迁移记录时返回明确的 404，不产生空文件。

## 安全与副作用边界

- 使用现有受管理员认证保护的 API；仅读取 SQLite，不访问百度 API，不读取或修改源/目标目录。
- 不导出 OAuth 凭据、管理员密钥或账号指纹。
- 下载由用户点击触发，文件名使用安全固定格式和迁移 ID。
- 超限返回明确错误，现有页面进度继续可用。

## 验收

- Store 测试覆盖一致快照字段、事件顺序、无记录、超过 100 条拒绝和关闭状态。
- API 测试覆盖只读 GET、附件头、404 和超限错误。
- WebUI 测试覆盖同源凭据下载、文件名、安全错误显示和不触发其他请求。
- 全仓 Go 测试、vet、WebUI/userscript、三平台打包通过。

## 不在范围内

- 不提供修改、删除、重试或恢复迁移记录的 API。
- 不把当前状态轮询历史化；只导出已持久化的 append-only 事件。
