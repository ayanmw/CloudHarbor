# .154 下载操作与诊断体验

.153 包已冻结。下一版在原目录内联实施；采用用户既有最佳推荐授权，不新增 worktree、自动提交、账号副本或真实远端写测试。五项全部达到后才打包；修订留在同版。

当前依据：App.vue 使用一个 error 同时表达本地搜索校验、连接失败和操作失败；连接标识/操作禁用直接依赖 error。cancel/retry 使用原生 confirm。操作成功没有独立页面反馈。信息面板只请求最新 20 条任务事件；已有 API 提供 before_sequence 翻页，面板仅显示少量事件字段。

本版交付：

1. 本地输入校验、读取失效和操作错误分别展示；超长搜索不再冒充连接异常。清单冲突和读取失效继续禁用不可靠操作，不放宽安全边界。
2. 取消/重试改成页面内确认对话框，明确任务名、路径及操作含义；取消不发送请求，提交期间防重复点击，沿用已有 vModal 焦点/键盘约束。
3. 暂停/恢复/取消/重试的结果提供页面内反馈；操作已接受但后续查询失败分别表达，不误导为动作未提交。不会自动重发 POST。
4. 任务信息中分页查看更早事件，沿用服务端游标并保持 sequence 字符串精度；切任务清空游标，迟到响应不得覆盖新任务。文件证据不请求不存在的子任务事件。
5. 事件显示类型、记录 UTC 和可用的发生/响应 UTC，尝试 ID、远端操作 ID 及证据默认折叠；缺失时间不推算，保留前往完整记录入口。

成功标准：构建 bundle 行为测试覆盖本地校验不影响连接、确认取消/单次提交、成功与读回失败分离、事件翻页/迟到隔离/大 sequence、UTC 缺失与证据转义；模拟桌面与窄屏检查；独立审查、完整发布门禁及包校验。测试只用本机夹具，不将其认定为真实账号/NAS 验收。

不新增云端写操作、不改变并发下载数、不回填历史。扫描不按猜测增加降频规则，明确限流响应仍沿用现有退避；用户可选次数上限仍标注为本工具设置。
