## v0.8.30-preview.139：全盘扫描覆盖快照历史

### 目标

每轮全盘扫描完成时，在同一 SQLite 事务内保存当时缓存覆盖状态、未完整目录数、缓存 generation 与本地观察 UTC。历史快照用于解释“扫描当时”的缓存；当前缓存可被后续远端操作或刷新改变，页面必须分别标注两者。旧运行没有快照时返回空值并显示“历史未记录”，不得依据当前缓存回填。

运行历史、单轮证据导出都包含这组字段。公共 JSON 响应不暴露内部 account fingerprint。扫描完成与快照/完成事件原子提交；任一写入失败，完成状态不得单独落库。

### 范围

- SQLite schema v37 增加 nullable 的历史覆盖快照字段，v36→v37 原子迁移，不改写旧历史。
- 完成状态事务中计算并持久化覆盖快照和 UTC 观察时间。
- 列表、单轮证据导出及只读 UI 展示历史快照，并明确当前覆盖可能不同。
- API/UI/迁移回归覆盖旧记录未知、事务失败回滚、generation 与 UTC、敏感字段排除。

### 验收

定向 taskstore/API/UI 回归、全仓 Go 测试和 vet、WebUI 与 userscript 测试、Windows AMD64/Linux AMD64/Linux ARM64 构建和预览包完整性通过。仅本机 SQLite/mock 验证，不执行真实网盘扫描或远端写操作。
