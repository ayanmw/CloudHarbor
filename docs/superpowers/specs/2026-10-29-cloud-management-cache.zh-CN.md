# 网盘管理与本地目录缓存设计

## 目标

为管理网页增加本地路径设置、网盘文件管理、全盘文件与目录缓存、目录大小统计、重复文件预览清理及空目录清理。用户可以在长时间扫描期间继续浏览网盘，后台任务在重启后可恢复。

## 已确认约束

- 网盘自动监控目录与本地下载目录可在网页查看和设置；有运行中下载任务时禁止修改。
- 本地目录迁移为可选操作。只有所有文件完成迁移并核验后才删除旧目录；文件占用或冲突时停止并保留源数据。
- 网盘文件管理仅操作远端，不提供上传。支持浏览、新建目录、移动、删除和重命名。
- 执行远端变更前暂停任务领取并等待正在运行的任务安全结束；变更后恢复队列并核对待执行任务。
- 用户指定项目通过移动到监控目录交由现有自动扫描机制发现，不再单独创建一条下载语义。
- 远端请求结果不确定时持久化为未知并隔离，不自动重发。对文件执行变更前重新核对 fs_id、路径及元数据。
- 全盘列表缓存为本地 SQLite 数据，不是远端实时事实。缓存完整性、扫描范围和观测时间必须可见。
- 目录大小通过全盘缓存本地计算；缺失或未完成缓存不得伪装成完整统计。用户可立即本地重算，也可启动/续跑后台全盘扫描更新云端观测。
- 全盘扫描分页、低并发、节流、遇限流退避、支持续跑；扫描期间仍可浏览缓存及实时目录。属于同一 Downloader 的目录分页请求共享可取消的最小请求间隔，避免后台扫描与交互浏览叠加突发请求；下载链接请求仍服从下载并发配置。
- 重复文件只能依据可验证的相同内容摘要与大小产生删除候选；摘要缺失或质量不足时不自动列为可删项。清理前展示拟保留项和将删除项。
- 远端操作、任务暂停恢复、缓存扫描与清理任务使用 SQLite 持久化关键事件、UTC 时间、云端观测时间、操作前后身份与结果状态。
- 不修改此前已存在的未提交工作；App 凭证和管理员登录行为沿用既有设计。

## 设计

### 配置与路径迁移

页面读取有效配置来源和当前路径。`.env` 或进程环境明确设置的路径优先并在网页中只读；未显式设置时读取稳定状态目录 `nas-downloader/queue/settings.json` 中的网页设置，首次使用则采用程序默认值。网页更新后立即生效并持久化。若有运行任务、未完成入队记录、扫描或远端维护，则拒绝更新。

应用状态目录固定在程序工作目录下的 `.nas-downloader`，不跟随下载目录改变。首次升级时，将旧下载目录内的队列状态逐文件复制并做摘要核验；确认稳定目录可用后，再移除旧队列状态目录。若新旧状态都存在但内容不一致，启动失败并保留两份数据供排查。Docker 部署必须把 `/app/.nas-downloader` 挂载到持久卷。

本地下载迁移由用户显式勾选启动，暂停队列领取并等待活动任务结束。迁移使用独立 SQLite 记录和只追加事件，保存绝对源/目标路径、目标监控目录、阶段、文件/字节进度、UTC 时间和错误原因。逐文件复制使用 SHA-256 和大小校验；相同目标文件可复用，内容冲突不覆盖并停止。全部核验后先将源目录原子改名为迁移暂存目录，再次核验，之后删除暂存目录并持久化新路径。每阶段可从重启恢复；任何前置失败保留源数据。固定应用状态目录不属于迁移内容。

### 任务调度门控与远端文件操作

增加可持久化的队列维护门控：停止新任务领取，等待活动任务收敛后执行远端操作；完成后通过一次完整监控目录扫描重建待执行观察，再恢复领取。异常退出后不恢复未确认的远端写操作；门控恢复时先核对并恢复扫描。对队列内任务按 fs_id 更新路径/名称，删除项写入取消/远端删除事件；活动或未知任务不做猜测性改写。

远端 CRUD 统一经单一操作服务执行，先列目录重新校验对象身份和目标冲突。异步响应、超时、断连或无法核验均进入 unknown，不重试；用户刷新/重新核对后才更新缓存。目录变更同步更新后代路径。

### 全盘缓存与目录大小

使用独立 SQLite 表保存账号身份、fs_id、父 fs_id、路径、名称、类型、大小、mtime、md5、观测时间和扫描状态。扫描游标按目录和页持久化；只有目录所有页及子目录完成后标记 complete。单页提交事务，避免崩溃留下半页。完整扫描以 run_id 标识，不删除未重新观测条目，直到相应目录完整核验后再清理陈旧记录。同一目录 fs_id 被观察到新路径时，在该页事务内清除旧路径下的缓存后代与目录状态；同一路径由新目录 fs_id 替换时，按旧 fs_id 删除旧根记录、清除路径后代，并让新目录保持 stale，不能误删本页刚观察到的新根条目。

目录大小从缓存的后代文件大小求和，返回字节数、文件数、目录数、扫描覆盖状态、缓存观测时间及是否可能过期。目录大小刷新只做本地计算；更新云端缓存由后台扫描承担。远端 CRUD 确认成功后对受影响子树、父目录和祖先目录做增量更新或失效；unknown 使范围失效。

目录大小聚合结果持久化在 SQLite，并按账号及路径保存。每个账号维护单调递增的本地库存代次；每个扫描页成功提交或远端操作使库存缓存失效时，同一事务递增代次。尺寸缓存仅在代次相同的情况下命中，否则从全盘列表缓存重新聚合后写入 SQLite。结果同时保留云端观测时间与本地计算时间；应用重启后可复用仍有效的尺寸结果。首轮查询仍需扫描目标子树，后续未发生库存更新时为常数行读取。账号级代次失效会使同账号其他路径的尺寸缓存一并重算，以换取简单且可靠的失效边界。

缓存目录分页按名称、fs_id 排序，SQLite 采用 `(account_fingerprint,parent_path,name,fs_id)` 复合索引直接提供父目录内的稳定顺序，避免大目录每次翻页都额外排序。v8→v9 迁移在同一 SQLite 事务内替换原父目录索引，并在重启时识别数据库已提交但 manifest 尚未发布的状态后安全完成 manifest 更新。

### 清理工作

重复文件清理先从完整且未失效的全盘缓存中筛出大小相同的文件组，再逐个流式读取百度网盘文件内容并计算 SHA-256；不把列表 `md5` 当内容证明，也不把文件内容写入临时磁盘。SQLite 按账号、fs_id 和文件身份保存摘要、校验时间与可恢复扫描游标；开始/暂停/退避重试/失败/完成有独立事件，429、网络超时和暂时认证不可用按递增间隔自动重试；SQLite 持久化退避毫秒数和 UTC 下次重试时间，重启后等待剩余间隔再继续。身份冲突和非暂时错误停止扫描。只有摘要校验完成且文件身份在读取前后保持一致的项目可进入预览。预览按摘要和大小分组，固定保留路径字典序最小的文件（fs_id 作平局排序），逐项列出明确删除候选及证据。执行删除时重新读取远端元信息、重新流式核验 SHA-256、再读取元信息确认身份后才发出删除；每次删除沿用远端操作日志，任何失败或结果未知停止本轮。网盘 API 不提供“条件匹配时删除”的原子操作，网盘外部客户端仍可能在最后一次身份读取与删除之间改动对象，页面需明确这一边界。

空目录清理基于完整全盘扫描结果，只从叶子目录向根部处理，并在删除前重新列目录确认为空；扫描不完整的目录不作为删除目标。用户确认删除后，每个目录独立写入远端操作日志；任何失败或结果未知都会停止本轮后续操作。

### 网页交互

新增网盘管理页面或同级导航入口，支持文件列表分页、路径导航、CRUD、目录大小、缓存扫描进度、重复项预览/执行、空目录预览/执行。后台长任务状态提供可折叠/收起面板，不阻塞页面浏览；返回阶段、页数、已处理条目数、错误/退避状态、开始/更新时间与可恢复状态。

### 安全与失败语义

- 云端列表缓存可能过期，所有写操作都必须实时重新核对身份。
- 任何不确定的写操作结果不得自动重发、自动删除本地证据或自动解除隔离。
- SQLite 证据缺失、损坏、账号身份不匹配或扫描状态不完整时，清理操作 fail-closed。
- 路径迁移失败不得删除源目录；不覆盖目标文件。
- 远端失败时恢复本地队列之前先核对监控目录，无法核对则保持队列暂停/隔离并在页面提示。

## 验收标准

1. 有活动任务时，配置更新被拒绝且原配置不变；空闲时重启后配置仍有效。
2. 本地迁移支持成功、目标冲突、文件占用及中途重启；SQLite 阶段与事件时间线可追溯，且仅完整核验后删除源目录。
3. 网盘 CRUD 操作先暂停领取并等待活动任务；成功后本地待执行队列及缓存反映远端结果，unknown 不重发。
4. 全盘扫描分页、限速、退避、断点续跑和重启恢复可验证；浏览在扫描期间仍可用。
5. 目录大小由已完成的缓存本地求和，展示数据时间及完整性；缓存缺失/部分扫描明确标记。
6. 重复清理只处理强摘要匹配的预览确认项；空目录仅在完整扫描并重新核空后删除。
7. 每类持久化变更均可从 SQLite 时间线追溯本地事件时间、远端观测时间、对象身份和结果状态。
8. 验证包含单元测试、SQLite 跨重启集成测试、API mock、构建和独立预览包 smoke；真实百度账号、NAS/SMB 与长时间限流验证单独标注。
