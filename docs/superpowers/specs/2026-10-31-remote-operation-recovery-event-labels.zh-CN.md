# 远端操作本地恢复事件说明

## 背景

重启恢复与 SQLite 故障处理新增了多种本地审计事件。远端历史页目前只显示状态、时间和 JSON，用户难以从事件列表快速区分“百度操作结果”与“本地缓存已失效/同步完成”。

## 方案

历史页为本地恢复类事件显示简短中文说明，包括 unknown 状态写入失败、unknown/confirmed 缓存恢复、缓存恢复完成、本地同步完成和缓存更新失败。原 UTC 时间及完整 JSON 证据继续保留并转义显示；未知事件类型继续显示原始证据，不隐藏、不改变远端状态或 API。

## 验收

- 页面能区分“本地缓存已失效”与“本地队列同步完成”。
- unknown 写入失败和重启恢复事件显示可理解的中文摘要及原始证据。
- 动态路径/错误内容 HTML 转义；其他未知事件仍能查看原始 JSON。
- 不新增 API 请求或远端写操作。
