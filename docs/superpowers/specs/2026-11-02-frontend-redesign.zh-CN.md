# 下载工作台与全站界面重构

优先级：最高。已获用户直接实施授权。基线提交 `48306e7`，主目录内联开发，不使用 worktree。

## 体验与技术选择

采用 Vue 3、TypeScript、Vite，构建后的静态资源嵌入 Go，离线可用。统一浅色工作台、固定侧栏、清晰标题与紧凑表格。借鉴下载软件的传输列表交互，不复制百度品牌或依赖官方客户端。

首页只展示根下载任务。点击进入独立详情视图，使用服务端分页文件表格，默认下载中优先、未完成其次、已完成最后；支持状态和名称筛选。文件夹只计数，不作为文件传输行，也不显示 0 B。已发现量必须标为“已发现”，根任务未结束时不将其宣称为最终总量。详情展示当前传输、速度、已完成字节及文件数；时间和完整路径放入展开详情。

根任务保留原有暂停、恢复、取消、重试能力与后处理策略，危险操作明确确认；unknown 隔离不变。重构不得把未完整遍历误作完成，不改已有任务的 keep/delete 策略。目录先在本地安全创建，保留目录状态供后台完整性与恢复使用。

网盘文件浏览成为网盘页首要区域。路径设置、缓存扫描/重复清理、运行历史移到清晰的工具导航；统一表格、按钮、空状态、加载与失败反馈。所有现有操作仍通过现有认证 API，账号与密钥设置边界不变。

## 交付和验收

1. 干净 Git 基线；新工作独立于基线可审阅。
2. 根任务聚合接口与文件详情分页，字符串 ID，目录不混入文件统计，边界/排序/筛选回归。
3. Vue 任务总览与详情，根任务操作和事件详情，加载/无数据/认证失效/失败处理。
4. 全站统一导航和视觉，网盘页信息重排及表格呈现，设置与历史可到达。
5. 本地目录预创建与空目录保留，失败关闭和取消响应。
6. 构建/定向回归/既有功能回归与浏览器实屏验收。真实运行任务不重启、不修改；验证新二进制使用隔离无凭据环境。通过后再更新同一预览版本。
