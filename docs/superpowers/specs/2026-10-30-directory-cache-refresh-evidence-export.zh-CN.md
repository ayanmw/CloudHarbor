# 目录缓存刷新运行证据导出

## 目的

`.88` 已让用户在网页查看历次目录缓存刷新运行及事件。本功能允许用户导出选定运行的完整本地证据，便于离线留存和排障。

## 范围

- 管理页选中某轮运行后，可显式点击下载 JSON 证据。
- 导出包含该运行摘要、按时间顺序排列的完整事件和导出时本机 UTC 时间。
- Store 在单个 SQLite 只读事务中读取运行摘要和事件，确保同一快照；仅导出当前认证账号下、包含 `started` 事件的运行。
- 最多导出 100 条事件；超过上限整份拒绝并保留原有分页查看方式。
- 事件中的账号指纹不进入导出；响应设置 `no-store`。运行 ID 必须是规范的 32 位十六进制。

## 不做

- 不访问百度网盘、不改变扫描状态、不更新缓存。
- 不新增筛选、批量导出、历史删除或 SQLite schema 变更。
- 不导出缺少 `started` 事件的旧历史。

## 验收

- Store 覆盖同事务读取、账号隔离、按序事件、缺失记录、超限整份失败和关闭数据库错误。
- Downloader/API 覆盖认证账号绑定、GET 限定、ID 校验、下载响应、敏感字段遮蔽、超限错误和不访问云端。
- WebUI 覆盖仅选中运行后显示导出入口、点击才下载、错误重试提示、文件名和异步切换运行保护。
- 全仓 Go 测试/vet、WebUI/userscript、Windows AMD64/Linux AMD64/Linux ARM64 构建及 ZIP 载荷验证通过。
- 本地 SQLite/mock 验收，不访问真实账号或 NAS/SMB。
