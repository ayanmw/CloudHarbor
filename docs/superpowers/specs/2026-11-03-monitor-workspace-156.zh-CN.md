# .156 自动监控历史工作台

依据：monitor-history仍为旧HTML/monitor_history.js生成列表及内嵌事件；API轮次/事件响应的next_before_sequence直接使用int64。选择一个完整只读页面迁移，继续用户要求的全站表格与证据体验，不扩展自动扫描行为或降频策略。

五项范围：

1. Vue紧凑扫描轮次表格，状态、监控目录、开始/结束UTC分列；常用状态/日期筛选、明确空/加载/失败状态，退出和全站导航保留。
2. 轮次及事件分页身份/游标精确字符串传输。先核对当前DTO，若为数字则采用显式兼容响应，旧客户端不受影响；不将已舍入数字转回字符串。
3. 受控URL恢复已提交状态/日期/轮次位置与选中的run；草稿不改变已应用查询，刷新和后退只读，未知操作参数不转发。
4. 单轮详情抽屉：区分本机开始/结束/云端观察时间及中断/错误分类，事件按页读取、证据折叠。切轮/查询时隔离旧响应，不推断中断为成功；新旧表格交互一致。
5. 单轮JSON导出反馈：绑定所选固定run，重复点击防护、失败/认证失效提示；切轮后迟到响应不开始错误下载，保留服务端脱敏和导出上限。

复用现有API，不新增SQLite表，不访问百度、不改变运行任务/监控/隔离状态。原目录内联，不worktree、自动commit/push或复制真实授权。.155包保持冻结。

五项达成后完成旧页能力对照、bundle与Go HTTP精度/权限回归、独立审查、桌面/390px/焦点验收及完整发布门禁，再打包.156；每项修订留同版本。真实账号/NAS验收单独标记。
