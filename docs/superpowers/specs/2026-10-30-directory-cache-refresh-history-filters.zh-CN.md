# 目录缓存刷新历史筛选

## 目的

运行历史增加后，用户需要从本地历史中快速找到失败、暂停或指定日期启动的刷新，而不是逐页浏览全部记录。

## 范围

- 网盘管理页运行历史支持按最新状态筛选：running、paused、failed、complete。
- 支持按启动 UTC 日期起止范围筛选，包含起止日；严格拒绝无效日期和起止倒置。
- 筛选在 SQLite 服务端执行；分页仍以不可变启动事件序号为游标，连续加载时保持筛选条件。
- 更改筛选或清除筛选后从第一页加载；既有运行选择、事件分页和完整证据导出仍绑定选中 run ID。

## 不做

- 不新增模糊搜索、事件级过滤、缓存刷新或远端操作。
- 不冻结多页之间的数据库快照；只保证新运行不会推动既有启动游标边界。
- 不新增数据库迁移。

## 验收

- Store 覆盖状态/日期组合、UTC 起止包含关系、keyset 分页、跨账号隔离和无筛选兼容。
- API 覆盖日期格式、范围顺序、状态集合、重复/未知参数校验。
- WebUI 覆盖筛选重置游标、向后分页保留条件、清除条件和旧响应保护。
- Go/vet、WebUI/userscript、三平台打包与 ZIP 检查通过；只做本地/mock。
