# 本地目录迁移历史浏览设计

## 目标

在路径设置页分页浏览 SQLite 中所有历史本地目录迁移，并能选择任一条记录导出对应的完整迁移证据。

## 方案

- 列表按 `started_at_utc DESC, migration_id DESC` 稳定排序，单页最多 50 条；摘要字段包含 ID、源/目标、状态/阶段、文件/字节进度及开始/更新时间/完成时间。
- 导出 API 按选中的 migration ID 查摘要和 append-only 事件；不得隐式退回导出“最近一次”，避免列表选择与证据错配。
- 摘要页和导出均使用只读 SQLite 查询；与百度 API、下载目录文件系统无关。
- 保留 `.66` 的 100 事件全量导出上限、UTC 证据和敏感字段遮蔽。
- 无迁移记录时列表返回空数组；未知 ID 导出返回 404；分页非法输入返回 400。

## 验收

- Store 覆盖稳定排序、分页边界、账户状态无关、非法分页、选定 ID 导出、unknown ID 和事件上限。
- API 覆盖查询参数、响应摘要、分页错误、导出 ID 精确匹配、404 和不触发外部操作。
- 页面选择任一历史记录后导出的文件名和内容对应同一 migration ID；旧请求不能覆盖当前选择结果。
- 全仓 Go 测试、vet、WebUI/userscript、三平台构建和 ZIP 检查通过。

## 不在范围内

- 不允许删除、修改、重试或续跑历史记录。
- 不读取迁移源/目标目录或调用百度 API。
