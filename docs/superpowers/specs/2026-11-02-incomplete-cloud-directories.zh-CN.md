# 网盘缓存不完整目录清单

## 目标

让网盘管理页把缓存覆盖原因的总数展开为可浏览的本地目录清单，并允许用户从清单直接选择本地缓存路径或把路径填入现有局部刷新控件。

## 行为

- 认证只读 GET 查询当前账号的不完整路径，支持状态过滤、路径关键字和稳定路径游标分页。
- SQLite 同一只读事务返回结果、总数与 `cache_generation`；客户端传入旧 generation 时失败关闭，提示重新加载第一页。
- 条目提供路径、状态/原因类别、缓存目录是否存在、最近百度观察 UTC 和来源 run ID；不暴露账号指纹。
- 清单覆盖缓存状态非 complete、缺少状态行、无缓存目录的状态孤项、父目录未完整及路径层级不一致等当前覆盖 SQL 判定的路径。
- 浏览清单和切换筛选只读 SQLite，不请求百度、不自动启动刷新。
- 用户点击“在缓存中打开”时只切换到本地缓存视图；点击“填入刷新路径”只填入现有目录输入框。发送请求仍须用户显式点击“刷新当前目录及子目录缓存”。
- 分页、筛选/搜索重置到第一页；缓存 generation 变化时不继续显示旧页。

## 验收（5 项）

1. Store/API 可按账号隔离查询完整不完整路径清单，并返回稳定分页、总数和 generation。
2. 可按路径关键字及缺失/目录状态筛选，能定位结构不完整但状态行 complete 的条目。
3. 结果显示状态和 UTC 证据，遵循账号绑定，不泄漏 fingerprint。
4. 页面按需浏览、筛选和分页；generation 冲突后回第一页，不把旧页与新总数拼接。
5. 页面提供只读缓存打开及刷新路径填充；不会隐式触发百度请求，只有用户点击现有刷新按钮才开始局部扫描。
