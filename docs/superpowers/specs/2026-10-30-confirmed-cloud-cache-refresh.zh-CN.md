# 已确认网盘变更后的本地缓存刷新设计

## 意图

网盘管理完成改名、移动、新建或删除后，若本地全盘缓存覆盖了相关对象，立即按百度操作回执更新 SQLite 清单和目录大小，让页面无需等待全盘重扫即可显示新状态。

## 当前行为

目录浏览直接读取百度实时列表。目录大小从 SQLite 全盘清单聚合。远端操作返回 confirmed 后，当前代码将涉及路径标为 stale；列表仍可浏览，但缓存大小会显示未完成，直到后续扫描重新覆盖相关目录。unknown 操作也会失效缓存并隔离对象。

## 目标

- 对 confirmed 的远端操作，仅在源父目录、目标父目录及涉及的目录子树在变更前均有完整缓存覆盖时，在 SQLite 单一事务中更新清单、目录状态和 generation。
- 让文件改名/移动、目录新建、文件删除、空目录删除以及缓存完整的目录改名/移动立即反映在本地清单与目录大小中。
- 对缓存缺失、不完整、身份不匹配、无法确认新建对象或事务更新失败的情况，保留当前保守行为：使受影响范围 stale，提示重新扫描。
- unknown / failed 结果不得套用增量变更。unknown 继续隔离对象并使受影响范围 stale。
- 写入云端变更确认时间；保留各项原有云端观测时间，避免将未重新读取的子孙对象误报为刚刚从百度读取。

## 非目标

- 不对缓存不完整的目录尝试猜测性补齐，也不运行隐式全盘扫描。
- 不改百度请求是否重发、身份核对或 unknown 隔离规则。
- 不声称缓存能反映其他客户端在本次操作之后作出的变更；用户仍可刷新目录并运行全盘扫描。
- 不改变网盘操作确认结果。远端 confirmed 但本地缓存更新失败时，操作仍显示 confirmed，并明确提示缓存需刷新/重扫。

## 方案比较与选择

1. 保持 stale 后依赖后台扫描。实现最简单且风险最低，但完整缓存上的常用 CRUD 也会让大小统计暂时不可用。
2. 对 confirmed 操作应用事务性增量更新；只有相关缓存完整且身份条件成立时更新，其他情况沿用 stale 后重扫。选用此方案，因为它满足本地即时更新需求，同时保留不完整缓存和 unknown 结果的安全边界。
3. 每次操作后重新枚举所有受影响目录及子树。实现语义直观，但大目录会增加百度 API 请求、延迟和限流风险，且不能消除分页期间外部变化。

## 行为约束

- 文件 rename/move：按 fs_id 定位原记录，更新 path、name、parent_path 和确认观测时间；若目标父目录或源父目录没有 complete 覆盖，则退回 stale。
- 目录 rename/move：对缓存中以旧目录路径为根的子树统一重写路径前缀及 parent_path；仅当旧父目录、目标父目录、目录本身及其所有后代目录均 complete 时应用。任何缺项或路径碰撞均退回 stale。
- mkdir：仅当目标父目录 complete，且操作后能从百度取得新目录的 fs_id/类型/路径时，插入目录记录并标记其空目录列表 complete；否则退回 stale。
- delete：按确认前复核过的 fs_id 删除对象；文件删除一条记录，目录删除其缓存子树。只有源父目录及被删目录子树覆盖完整时，才更新 generation 并保留完整状态。
- 单次增量更新中的清单变更、目录状态和 generation 必须同一 SQLite 事务提交。事务失败不得留下部分重写。
- 全盘扫描正在分页读取变更源/目标父目录，或扫描队列仍包含即将移动/删除的目录子树时，必须在发送百度写请求前拒绝该次操作，要求先暂停扫描；避免 offset 游标或持久化待扫路径指向旧目录。
- 远端确认后若缓存更新失败，记录诊断并尝试 stale 失效；返回 confirmed 操作结果和本地缓存刷新警告，不返回操作 unknown。

## 验收标准

- 单元测试证明文件 rename/move/delete、目录 rename/move/delete、mkdir 后目录大小与列表立即正确。
- 覆盖不完整源/目标父目录、不完整子树、fs_id 或路径不匹配、目标路径碰撞、无法读取 mkdir 新对象、unknown 结果及 SQLite 注入失败时的 stale/隔离行为。
- 扫描页提交与增量更新并发时，generation、路径和缓存状态不得回退或混用。
- 关闭并重开 SQLite 后，更新后的路径、大小、完整状态和确认时间一致。
- 真实账号仅对自建空目录及可丢弃小文件做有限 CRUD 复核；不对用户现有目录执行清理。

## 实施假设

按 preview.53 的同步成功分类作为远端确认凭据；所有增量数据来自请求的已核验对象和本次确认操作。无法从接口确定新对象身份时不猜 fs_id，回退 stale。对非空目录删除也只有在完整缓存且操作确认成功时才移除其缓存子树。
