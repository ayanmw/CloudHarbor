# v0.8.31：展示大小排序与统一目录地址栏

状态：源码修复与本机自动检查完成，尚未合入运行包/视觉及真实百度验收。目录地址栏、显示大小同事务快照、完整目录排序及固定快照分页后端与前端Size接线均已完成；最终610项前端、相关Go定向与vet通过。来源为用户体验反馈，当前安装身份仍以版本说明为准。

## 问题与目标

当前ListCloudOrdered先请求百度按provider size排序/分页，再将完整缓存目录的Size替换为递归Bytes；排序依据与显示数值不一致。新要求：点击Size按显示的实际字节数排序，目录采用已计算缓存大小；相同大小时名称始终升序，不能随Size降序反转。导航整合为资源管理器式工具条，后续统一参考成熟百度网盘/资源管理器的布局，而非继续堆独立控件。

## 展示大小排序

1. 明确分开display size与provider size。文件按线上文件大小；目录按完整缓存递归汇总。目录未知/不完整不伪装0B，不回退网盘目录原始0参与已知大小排序；未知组始终置后，并明确缺口与刷新入口。
2. 先获取并核对当前目录全部直接子项的线上清单，结合本地目录大小快照，完成全目录排序后分页。不得只重排当前100项。只读取本目录的列表页，不为排序自动递归扫描子目录或全盘；缺失的子目录大小由用户显式刷新缓存。
3. 主键：大小按用户指定升/降序；第二键：统一名称升序，Size降序时第二键仍升序；名称相同再用路径/精确文件ID保证稳定顺序。按原始整数字节比较，不按格式化后的KiB/GiB文本比较，不丢失大于2^53的精度。
4. 一轮排序绑定远端清单观察、账号/应用/缓存作用域、大小快照/代次和排序规则。翻页沿用同一排序快照；本地刷新或已知远端操作导致快照失效时明确提示/重建，不跨页混代、不静默重复或漏项。首次准备显示读取进度、可取消；换目录与离页隔离迟到结果。
5. 默认目录清单在线核对；缓存仅辅助大小。观察UTC与缓存统计时间分开，不声称远端原子快照或绝对实时。错误/取消保留可识别旧结果，不将半份清单发布为完整排序。
6. 缓存汇总大小不得写入远端身份核对字段。入队、移动、改名、复制、删除继续使用provider_size、ID、路径、mtime等既有线上证据，预检与未知隔离规则不变。
7. 本轮不承诺名称/时间排序等值项的远端合同，也不扩展为类型/目录优先排序。旧文档“目录缓存不参与大小排序”仅描述旧实现，被本设计的新目标替代。

## 统一目录地址栏

布局：后退、前进、向上、路径栏作为同一工具条；刷新靠近地址栏，搜索保持独立清楚的入口。删除重复的分散上级/打开目录/面包屑行，沿用现有Header和侧栏，不再增加导航层。

- 默认路径栏显示紧凑可点击面包屑，任意祖先可直接跳转；末段明确当前位置，根目录有独立状态。
- 点击路径栏空白或编辑入口进入绝对路径输入；Enter打开，Esc撤销并恢复当前路径。长路径不撑宽页面，保留完整路径查看/复制能力，窄屏可横向滚动。
- 后退/前进是本工作台的位置历史，不通过history.length猜测，也不把用户带到外部页面。成功打开新位置才推进；失败不污染位置历史。从历史中间打开新目录裁剪前进分支。
- 目录切换记录位置；刷新与缓存大小重算不新增历史项。排序、分页、搜索条件作为当前视图状态保存，返回对应位置时恢复。兼容浏览器前进/后退、直接链接、BFCache与重新加载的可用状态。
- 根目录的向上禁用；没有对应历史时前进/后退禁用并有解释；键盘焦点与可访问名称完整。加载中可取消/替换读取，不能迟到响应改写新地址；执行中的远端写操作不能因导航被判定未发送。
- 空目录、列表错误和未授权时导航外壳仍存在；区分正在请求的地址与最后成功显示的地址，失败不把旧表格冒充新目录。

- 地址栏：祖先跳转、编辑/Enter/Esc、根目录、历史分支裁剪、无历史、失败不入历史、返回恢复视图；浏览器历史/BFCache、迟到响应、键盘与窄屏分别验证。
