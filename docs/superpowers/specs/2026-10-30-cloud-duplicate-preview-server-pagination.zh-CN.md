# 重复文件预览服务端分页

## 目标

把重复文件预览从“完整结果一次返回、浏览器只分页渲染”改为 SQLite/API 按页读取，限制常规浏览时的单次响应和页面持有量。保留全部预览删除能力、每组保留项选择和逐文件远端身份/内容复核。

## 行为

- API 接受非负 `offset` 与 `limit`，限制 `limit` 为 1–50，返回当前页 `groups`、总组数、总待删除文件数、offset、limit 和可空 `next_offset`。
- SQLite 在同一只读事务中读取当前页与总数；组按 SHA-256、文件大小稳定排序，组内副本按路径、fs_id 排序，默认保留首项。
- 页面每次只保存并渲染当前页；翻页请求下一页。保留项覆盖按 SHA-256 和文件大小索引，跨页仍有效；刷新预览清除覆盖并从第一页加载。
- 单文件删除继续使用现有确认、身份及 SHA-256 复核接口。确认成功后刷新当前页并更新全局计数。
- 批量删除确认文字使用服务端返回的完整待删除数量。确认后反复读取第一页，处理其第一组内的候选项；一组全部处理完后重新读取第一页，直到没有组。这样删除造成分组消失不会让 offset 跳页。任何失败或 unknown 立即停止，保留现有隔离规则。
- 若在批量删除中候选身份变化、组数据已变化或预览读取失败，立即停止，不跳过继续处理后续项目。
- 当后台刷新使既有保留项身份不再出现在组中时忽略该覆盖，使用最新页默认保留项。

## 边界

- 仅本地 SQLite 提供预览分页数据；分页不请求百度 API。只有用户确认单项/批量删除才调用既有远端变更 API。
- 本版不创建跨请求持久化快照。每页读取是一个 SQLite 一致快照；若后台缓存变化，逐项删除仍由既有身份和摘要复核阻止对旧对象执行删除。
- 不改变 SHA-256 扫描、云端去重判定、扫描限流或失败隔离语义。

## 验收

- Store/API 覆盖空集、页边界、稳定排序、总删除数、无效 offset/limit 与账户隔离；当前页和计数在同一读事务内完成。
- UI 覆盖第一页/中间页/末页、翻页请求参数、跨页保留项、刷新清除选择、成功删除刷新、批量删除逐组从第一页续取、失败/unknown 立即停止。
- 常规页面仅持有不超过 50 个组；不通过浏览所有页重新拼接完整数组。
- 全仓 Go 测试、vet、WebUI/userscript、Windows AMD64/Linux AMD64/Linux ARM64 构建、ZIP/来源快照/敏感运行数据核验通过。
- 不对真实百度账号执行删除；远端行为由 UI mock/API 回归验证。
