# 下载任务列表筛选和搜索

## 目标

在 WebSocket 与轮询两种下载任务页面，按任务状态筛选，并按云端路径或文件名搜索，帮助管理员在较长队列中定位任务。

## 行为

- 页面增加状态选择器和路径/文件名搜索框；输入去首尾空格，大小写不敏感，按字面子串匹配。
- 状态与搜索条件组合；条件变化时重置到第一页，排序、前后翻页和自动刷新保持当前条件。
- 查询继续由服务器分页；只返回当前命中页，不把完整队列发送到浏览器。
- 显示筛选命中总数与全队列总数；现有状态统计卡片保持全队列统计，不随筛选变化。
- GET `/api/status` 与 WebSocket `status_page` 使用相同筛选语义；无筛选时保留既有输出和排序行为。
- 状态仅允许 `pending`、`downloading`、`retry_wait`、`auth_wait`、`source_unknown`、`failed`、`cancelled`、`done`；搜索最多 128 个 Unicode 码点。非法状态、重复参数、过长搜索拒绝，不执行查询。
- 结果只读取当前内存任务投影；不写 SQLite，不触发百度请求、扫描或任务操作。

## 验收

- Downloader 回归：状态/路径/文件名组合、大小写和空格、排序/分页稳定、命中数与全局状态数区分、无筛选行为不变。
- HTTP 回归：状态/搜索分页响应、筛选命中数、重复/非法/过长输入 400。
- WebSocket 回归：状态和查询进入页面请求，非法筛选不更新活动分页条件。
- WebUI 回归：两个页面均可筛选，条件变更回第一页，换页/轮询/WebSocket 更新保留条件，清空后恢复全列表。
- 全量发布门禁：Go 测试、vet、WebUI/userscript、Windows AMD64/Linux AMD64/Linux ARM64 构建、ZIP 与源码快照校验。

## 非目标

不增加任务重试、取消、恢复、批量操作或事件导出之外的证据处理；不改变任务保留策略、SQLite schema、远端状态和队列持久化格式。
