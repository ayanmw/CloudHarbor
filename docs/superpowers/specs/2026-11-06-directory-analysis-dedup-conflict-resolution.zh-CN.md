# 文件去重、目录分析与同步冲突处理

状态：当前v0.8.31已同版交付只读目录比较、固定报告/分页导出、范围去重、文件/目录冲突决策与明确选择的批次核对、执行、整体复核。真实单项、目录归档/保留两份、批次成功/过期/中途变化停止及重启证据已记录，固定入口有界扫查与完整发布门禁已通过。后续以版本要求证据审计及环境边界为准，不把历史过程中的待覆盖描述当当前状态。沿用主目录，不切版、不创建worktree、不提交/push。

## 当前已核实的能力和缺口

- 网盘去重已有已验证SHA256分组、保留副本选择、固定清理批次和执行前线上核对。
- 目录已有列表、大小、缓存覆盖和刷新变化记录；目录分析按完整结构与可信内容比较，不能用“大小一样”证明目录重复。
- 目录同步已有本地/远端索引、成功共同基线、逐项冲突与历史快照；新增冲突决策工作区及固定单项/批次流程已接通源码，必须通过独立当前复核才推进共同基线。

## 产品结构

统一比较证据和对象定位，保留三个清楚入口：

1. 文件去重：查找内容相同副本，选择保留位置，预览整理影响。
2. 目录分析：比较两个网盘目录，或一个同步关系的本地/网盘目录；目录大小、文件数量、完整覆盖、独有/重复/冲突项目用表格呈现。
3. 同步冲突：从冲突项进入对应比较结果，选择处理方案，复核后执行，再次同步验证。

默认分析范围为用户明确选择的目录或现有同步根；不扫描任意本地磁盘，也不把缓存分析自动扩展为全盘删除。只读分析不触发清理、覆盖或同步执行。

## 比较和去重规则

- 文件内容相同需有同大小和可信SHA256，摘要绑定身份、路径、大小、元数据及核对证据。未校验文件只标记待核对，不进入可删除结论。修改时间不决定哪份更有价值。
- 区分同路径同内容、不同路径同内容、同路径不同内容、仅本地/仅网盘存在、身份变化、删除对修改、文件/目录占名冲突。
- 完整重复目录要求相对路径、项目类型、空目录结构和文件内容均一致，且两边完整遍历；同大小/同数量不能判重复。
- 单独呈现“内容集合相同但目录结构不同”和“部分重合”，保留重复文件数量/多重性；不能把集合相似等同可直接删除整个目录。
- 目录摘要使用明确版本、确定排序和无歧义编码；覆盖不完整、大小写冲突、链接、缺失摘要时不发布完整重复结论。
- 分析显示历史快照的观察UTC、摘要校验证据及覆盖范围，刷新生成新分析ID，不覆盖旧报告。执行必须重新核对当前两端，历史缓存只供候选和解释。

## 冲突工作区

表格列：冲突类型、相对路径、本地/网盘/上次共同基线、大小、内容摘要、修改时间与观察时间、建议方案、处理状态。选择一项后显示紧凑的前后对照；提供定位文件、查看重复组、查看目录分析和关联记录。

可选方案及方向约束：

| 方案 | 网盘→本地模式 | 双向模式 |
|---|---|---|
| 保留网盘 | 备份本地旧内容后更新本地 | 备份被替换内容，使两端采用网盘版本 |
| 保留本地 | 保留本地并继续标记未解决，不隐式上传；需另行明确变更同步模式 | 备份网盘旧对象后上传本地版本 |
| 保留两份 | 本地旧内容保存为明确命名副本，网盘版本落到原路径；不上传本地副本 | 两端均保留两个明确命名的版本，并重新核对内容 |
| 暂不处理 | 无写操作、保留冲突与旧基线 | 同左 |

默认不自动选择较新文件，不自动批量覆盖不同内容。保留两份使用可预览且不会覆盖现有项的目标名，固定到决策记录；目标被占用时要求重新预检，不能临时猜名字或盲重发。文件/目录类型冲突、删除对修改和非空目录处理分别列明影响，不隐藏为一般文件覆盖。

用户作出决策后先生成固定预览：对象、来源、目标、影响文件数、复制/上传/下载/移动/删除步骤、备份位置与失败边界；确认预览后执行。批量只作用于明确选中的项目，不默认全选，也不把一次选择变成未来自动策略。

## 证据与恢复

保留原冲突运行和原分析报告；决策写入SQLite，关联父运行、步骤/冲突标识、两端预期身份/摘要、选择、固定目标路径及UTC。执行生成新批次，记录每一步intent和回执；旧冲突不能被改写成历史上已成功。

只有当前内容复核及新一轮同步通过，才推进共同基线、关联“该冲突由哪个新批次解决”。部分失败不标全组解决；未知写入继续隔离，无凭据不重发或强行放行。重启后保持决策、固定名称、已确认步骤及未知状态。

## 验收与实施顺序

1. 先补只读统一目录/内容比较：精确重复、结构不同、部分重合、覆盖不完整和冲突分类。
2. 再完善去重工作区：目录范围、保留位置、可释放空间、逐项影响、目录分析与定位联动。
3. 最后接冲突决策及执行：单项先于批量，保留方向边界、备份、预检、记录和复核。

单元/SQLite故障注入覆盖目录摘要、重复多重性、乱序列表、大小写/缺摘要、过期决策和中断。真实账号在独立测试根验证同内容副本、同名异内容、目录结构不同、双端冲突、删除对修改、目标占用及重启；不使用用户原有文件作为整理或删除夹具。
