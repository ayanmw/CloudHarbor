# v0.8.33 本站只读文件库设计

用户已于2026-11-17明确开始下一版并实施；承接v0.8.32正式Release提交7f2fe24。目标仅为单用户、单文件库的安全配置→浏览／当前目录文件名搜索→版本校验下载→失败与重启恢复闭环。无本地上传、改名、移动或删除，无Client、设备token、多用户和公开分享。既有管理员表单会话／Bearer保护所有新接口，不依赖百度授权。

## 技术选择

沿用Go/Vue/SQLite，不引入AList/OpenList整套应用或rclone进程。当前只读本地访问可由标准库完成；Go源码最低版本提升到1.24以使用`os.Root`，CI继续固定1.27.1，源码Docker同步编译工具链。`os.Root`的受限句柄访问比先清理路径再普通Open更能抵御路径替换竞态：[官方说明](https://go.dev/blog/osroot)。不承诺防御拥有本机文件系统控制权的管理员创建硬链接／挂载或修改正在传输的文件。

新建`internal/library`，独立SQLite位于StateDir/library/library.sqlite，不改现有任务数据库schema。配置、目录观察和错误证据单独持久化。采用单事务建表，保持DELETE journal、EXTRA同步、外键和busy timeout。无凭据复制，无用户文件写入或迁移。

## API与文件边界

- `GET /api/library/config`读取当前根配置和配置版本；`POST`以`{root,expected_revision}`保存，拒绝过期配置及正在浏览／下载时的切换。配置首次为空，用户显式选择目录，不默认发布下载目录。
- `GET /api/library/entries?path=&query=&offset=&limit=`刷新该目录的真实文件系统观察，完整成功后原子替换SQLite快照，分页返回。仅当前目录文件名搜索，不伪装全盘索引。失败保留最后成功观察，返回stale/error及观察UTC，网页禁用历史条目下载。
- `GET/HEAD /api/library/content?path=&revision=`校对列表中的元数据观察版本，打开受限只读句柄，计算SHA256作为内容ETag，支持HTTP条件请求与Range。列表revision不是内容hash；ETag是在本次下载准备时校验的内容。校验后再核对句柄元数据，发现变化拒绝。传输期间外部原地写入不具有文件系统快照保证，不宣称同步完成凭据。

相对路径仅允许规范的`/`分隔形式；根用空字符串。拒绝绝对路径、父目录、反斜杠、Windows ADS／保留设备名及符号链接／junction；查询参数只解码一次，不对字面百分号路径重复解码。打开文件前后校对身份；目录列表不跟随链接、不展示已知私有目录。每次读重新验证根身份与已知保护路径，目录换盘／替换不能沿用旧身份。

保护StateDir及其祖先／子目录、旧下载目录内私有状态目录、工作目录.env；目录项中的`.nas-downloader`、`.git`、`.nas-sync-history`和`.env`不发布。配置根若包含已知保护路径必须拒绝，不靠列表隐藏掩盖根配置越界。数据库持久根身份，重启后只读核对，不自动接纳新根。

当前目录分批读取，单目录最多100000个条目，超过明确报错并保留旧观察，不以部分列表替换完整快照；网页每页默认50、最大200。观察只记录当前目录，没有递归全盘扫描或同步删除推断。SQLite记录观察成功／失败时间、数量及摘要；旧内容仅辅助显示，不作为下载权限与完成证据。

## UI

顶栏新增“本站”模块与“本站文件”侧栏，和百度“网盘文件”分开。未配置时提供路径表单，配置后可折叠更改；显示只读说明和根可用状态。面包屑、向上、当前目录搜索、刷新、紧凑表格、文件类型图标、可读大小、修改时间、分页与下载。保留查询路径／搜索于URL，迟到响应不能覆盖新目录；加载、空态、错误和历史观察均可见。大文件下载前内容校验可能耗时，明确提示；不通过fetch Blob把大文件整体装进浏览器内存。
