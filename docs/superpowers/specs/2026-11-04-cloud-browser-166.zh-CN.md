# 网盘浏览与上传改进设计

用户八项反馈明确授权，沿用Vue/Go/SQLite，主目录内联；不worktree/commit/push，保留既有改动。采用推荐方案直接实施，不重复确认。

1. 全站容量默认IEC可读单位B/KiB/MiB/GiB/TiB/PiB/EiB，BigInt计算与四舍五入，原始字节放title用于核对，不改身份或API数值。
2. 网盘文件作为唯一浏览入口，目录/文件下载按钮链接/intake?path=精确路径。二级页仅做所选路径预检、确认移动，保持既有隔离/身份/过期保护；入队历史独立/intake-history菜单，旧/intake无path保留兼容旧书签/脚本的浏览入口，主菜单只保留网盘文件和独立入队记录。
3. 紧凑带边框按钮、每行操作组、图标及目录层级；已知操作不可用给出原因，不静默返回。新建目录检查浏览器错误及子目录操作链路。
4. 默认实时网盘列表，移除来源切换；保留旧缓存深链接兼容为明确搜索结果，不让缓存替代实时目录。搜索始终可见，完整缓存优先；不完整时明确可用范围，提供刷新缓存，不声称全盘无结果。
5. 页状态展示可读的文件字节总和、含目录缓存的大小（不完整标已知部分）；不把重叠搜索目录重复加总当精确全盘。顶部缓存状态按钮展示进度并链接缓存工作台。
6. 文件夹/常见扩展类型图标，未知用默认文件图标，图标aria-hidden，名称仍可访问。
7. 上传单独实现计划：浏览器多文件/目录选择→本机持久暂存→SQLite批次/逐项进度→百度预上传/分片/合并→线上核对。跨重启记录保留；浏览器未完整传入的文件明确等待重新选择，不冒称可继续。文件名/相对路径规范化拒绝穿越；不覆盖同名文件；上传目标和用户确认固定，账号绑定、并发有界，错误不得泄漏token。服务重启时不盲目重发结果未知的合并。上传需独立菜单与批次详情，成功刷新列表/失效缓存。

验收：容量边界/大int；子目录mkdir弹窗与一次确认；下载入口与独立入队记录；实时列表/常显搜索/缓存状态/页大小；紧凑图标界面。上传另测真实provider合同mock、SQLite中断恢复、批次失败/冲突/取消/未知证据及可见UI。不在真实账号任意创建/上传/删除试验数据。整批完成前不发布半成品，不拆小版本；最终账号唯一状态迁移至当前版本并核验。
