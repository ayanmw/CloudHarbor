# 全盘扫描单轮证据导出

## 目的

管理员需要把某一轮全盘扫描的摘要和关键事件交给本机排查流程留档。导出必须来自同一份 SQLite 只读快照，不能把不同时间读取到的摘要和事件拼成一份证据。

## 行为

- 用户选择一轮扫描后，显式点击导出按钮才下载 JSON。
- 文件包含单轮运行摘要、按记录序号升序排列的关键事件、总事件数和导出时 UTC 时间。
- 查询在一个 SQLite 只读事务中完成；事件最多 10,000 条，超过上限时整份拒绝并返回可读错误，不截断事件。
- 导出使用显式字段 DTO，不输出内部账号指纹。此功能只读取本机 SQLite，不访问百度 API，也不改变扫描状态。

## 验收

- 运行摘要与事件来自同一只读事务；事件时间/顺序稳定且运行 ID 一致。
- 第 10,000 条以内可以完整导出；第 10,001 条时无部分文件并返回 413。
- 未选择扫描时不发请求；用户点击后才发起附件下载；失败时页面保留错误提示。
- JSON 中不出现 `account_fingerprint` 或内部账号指纹值。
- 使用本机 SQLite/mock 验证，不将结果视为真实百度或 NAS/SMB 验收。
