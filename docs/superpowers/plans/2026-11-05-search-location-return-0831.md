## 设计
P0-D搜索结果定位所在父目录，并显式返回已提交搜索：查询/范围/类型/偏移/缓存代次通过受限本地URL保存，刷新和浏览器返回可恢复。不保存未提交草稿，不使用任意跳转地址。
定位对象只携带缓存fs_id/path/directory，实时目录仍由远端读取；同ID/路径/类型匹配才高亮和聚焦。同路径不同身份提示变化；本页没有匹配不宣称全目录不存在，允许正常翻页。不自动扫描整个目录、不自动勾选或发送写操作。
仅接受live目录中的定位，目标必须为当前目录直接子项；return_search必须是无嵌套定位的本站缓存搜索路径。分页/刷新/排序保留定位，离开父目录可清除。返回显式重新读取保存条件，代次变更走既有恢复，不展示旧页当实时结果。
