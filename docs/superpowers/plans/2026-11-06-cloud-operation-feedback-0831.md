# v0.8.31 文件操作结果反馈

## 设计与边界

最近操作卡片当前在长文件表后，确认/失败/未知结果难以发现。采用小型只读CloudActionFeedback组件，放在列表上方而非底部；不做全局通知框架、不新增API/重试/放行，不改写远端证据。来源和目标分字段，不用空箭头表达删除。

## 实施与成功标准

1. 先加行为回归：操作后反馈在文件表前，成功/未知分别可见且有状态语义；有可信格式operation ID时直达该记录，无ID时只去记录中心。未知不提供重试/清除。
2. 新增只读组件，主页面复用既有actionResult，不改变busy、refresh、unknown保护和生命周期；来源目标允许长路径换行。标明仅本页最近一项，历史见记录。
3. 类型/构建、全前端、模拟桌面/窄屏与键盘检查；独立复核后合并同版发布，保留数据。不切版不提交。

空来源/目标不编造，消息按普通文本渲染。结果状态不因刷新列表成功而升级。没有远端operation ID的网络中断不猜造ID，页面结果不是持久历史。
