# v0.8.31 批量移动/复制在线冲突预览

## 目标和边界

补齐P0-A4确认前的整批在线观察。复用现有账号、云端读锁、身份比较和分页边界；正常预览不主动暂停队列、不创建预览或远端操作记录、不改缓存或发送网盘变更。若百度拒绝授权，仍沿用已有reportAuthenticationFailure，全局账号失效/队列等待授权可能持久化状态；不能禁用这一保护来承诺绝对零本地写入。最终仍用既有MutateCloud逐项重新核对。预览不是锁或完成凭据。

## 协议与执行

新POST /api/cloud/mutations/preview（鉴权、同源保护沿用管理层，no-store）。POST仅携带受限身份数据，处理仅线上读取。固定operation(move/copy)、destination_directory、expected身份清单及request_id。phase=sources时每次1..10来源，逐个GetFileInfo；phase=destination时1..100预期名称，按100项分页，offset>0必须带上一lookahead指纹。边界变化返回需重新预览，不自动拼接重锚结果。全部数字身份输入用规范十进制字符串；结果来源/冲突ID同样字符串。

响应回显request_id/phase/operation/directory/offset，包含本机开始与读取UTC、source阶段逐项身份一致/变化结果，target阶段每项最多一个页内同名例子（Go EqualFold，不是所有同名对象清单）、最多n−1个本批重复名称关联、本页数量及next_offset/next_boundary。请求ID只关联响应，不作为授权或持久凭据；缺页/失败不得称整批无冲突。现有交互分页上限若触达明确失败，不把截断当完成。
