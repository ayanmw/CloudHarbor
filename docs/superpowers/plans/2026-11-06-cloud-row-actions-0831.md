# v0.8.31 文件行操作密度收敛

## 设计与范围

源码确认网盘每行常驻信息/下载/改名/移动/复制/删除六项。保留信息、下载和有边框的更多按钮；四项变更操作置于当前行展开区。不是ARIA菜单，不引入不完整的menu键盘模型；用aria-expanded/controls和命名group表达披露区域，Tab按文档顺序进入。展开不发送请求，实际操作仍进入原确认页，不新增远端动作。

一次仅展开一行；Esc关闭并返回触发按钮，点击外部关闭。选择具体操作先收起并聚焦触发按钮，再打开既有弹窗，使弹窗关闭后焦点返回可见入口。加载/失败/未授权/操作忙时禁用；列表替换、离页和恢复时清除展开状态，不跨对象保留。未知结果的四项变更按钮继续禁用。

展开区在行内布局，仅展开当前行时增加高度，避免绝对定位浮层被表格滚动容器裁切。搜索缓存行保持信息及实时核对入口。水平重复导航此次仅盘点，不同时改动，以减少已交付页面的变化范围。
