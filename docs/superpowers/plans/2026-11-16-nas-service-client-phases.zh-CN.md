# NAS 服务与 Client：分阶段候选计划

状态：规划草案，不是开发授权。活动版本 v0.8.32；后续版本号仅在用户人工确认切版时确定。依据[设计](../specs/2026-11-16-nas-service-client-design.zh-CN.md)。

| 阶段 | 完整体验与范围上限 | 验收出口 |
|---|---|---|
| P0 复用决策 | 固定候选提交、许可／依赖核对；验证受控目录、续传、取消、重启、日志接口；输出采用或否决理由 | 不把多引擎叠加作为默认；不能满足本站隔离与证据合同则拒绝，无长期实验分支 |
| P1 本站文件库 | 一处明确文件库、网页浏览和基础管理、上传下载、暂存发布、最小回收与扫描索引 | 无百度也可用；目录离线不删索引；重启处理未完成写入；权限外路径／链接拒绝；现有下载数据不迁移 |
| P2 下游可用闭环 | 每设备 token、根目录权限、轻量 Client 两项配置、单次／手动上游→本地同步、断点与批次记录 | 两台设备互不干扰；权限撤销／路径变化即停止；离线重连正确；同名冲突不覆盖；客户端游标落盘后才推进 |
| P3 持续同步与上传 | 手动触发稳定后再加周期；Client 独立上传任务；统一限速与暂停，百度→本站完成后可发现 | 半成品不可见；单段失败可定位；重试幂等；原始下载完成策略不误删本站发布文件 |
| P4 双向同步 | 共同基线、双端改动、移动／改名、删除恢复、预览与明确冲突决策 | 首次合并不传播缺失；多端同时改动保留内容；过期基线重核；损坏缓存／磁盘离线不扩大删除 |
| P5 扩展 | 多用户、分享、其他平台、WebDAV及更多云盘按需求另拆 | 逐项定义权限和性能标准，不以“所有网盘功能”为完成条件 |

P0 为开发获批后的小型选型验证，不在当前“仅设计”任务中执行。阶段不是固定一阶段一版：P1 可作为一个完整版本候选，P2 要同版交付服务端＋可用客户端，不能只发布一堆 API；P2 只是首个可用单向同步闭环，不代表包含 P3 独立上传在内的完整 Client 已完成。超范围能力另版，未经用户确认不进入。

实施前置清单：确认范围与首个 Client 平台；批准详细设计与切版；核对唯一用户数据、脏工作区与存储根；确定开源许可与组件固定版本。每版维护内容说明、验收缺口和源码快照；测试版只覆盖程序，不覆盖数据。不为路线图自动提交、推送、打标签或启停服务。

逐阶段验证至少覆盖：正常流程、取消／网络失败、重复请求、进程中断恢复、部分内容校验、越界访问、权限撤销。NAS/SMB、自然断电及多机实测需独立环境证据；本机测试不可替代。所有文件操作日志带批次／操作 ID、设备、相对路径、UTC 与证据来源，绝不记秘密。
