# v0.8.31 Header后台任务快照

## 设计

固定Header增加只读后台任务入口，默认关闭且不发请求。打开读取下载队列摘要、上传真实准入快照、全盘缓存扫描、目录刷新、内容哈希扫描五个独立来源，表格显示摘要/观察时间/详情链接。下载计数来自队列状态，不冒充活跃worker；上传准入/收尾和扫描worker字段单独说明。快照不是实时广播，不展示无依据的绿灯或合计。

复用现有GET，五来源并行且独立失败，单项读失败保留旧值并明确历史。仅手动刷新；关闭、pagehide、unmount、外部inert和新一轮请求均使旧请求失效，旧401不能污染重新打开的面板。当前401中止这一轮读取并显示登录入口。Escape/关闭恢复触发焦点。无远端写入/控制按钮，清理删除批次仍去原页面查看，不能用hash扫描概括全部清理。
