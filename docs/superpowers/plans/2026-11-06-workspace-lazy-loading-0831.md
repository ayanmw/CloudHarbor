# v0.8.31 工作区按需加载

问题：main.ts静态导入所有14个工作区，单JS534.63kB；访问诊断等小页也加载全部传输/整理页面。

方案：按pathname动态导入选中工作区，保留原路由与默认下载页；共享Vue/Header等由Vite抽取。使用同一份全局CSS（cssCodeSplit=false），避免浏览器等待不可用样式事件导致挂起，暂不优化样式拆分。引导页加载/失败/重试均有可见文本；动态模块失败不得自动重发业务请求。无需增加Vue Router。

测试：node vm.SourceTextModule在JSDOM上下文执行真实构建ES模块，静态/动态依赖从发布app根读取并隔离每个DOM模块缓存；await入口顶层加载完成再断言。npm test通过专用Node入口启用vm模块；不另构建测试专用代码。新增验证诊断页不加载上传/网盘等工作区、各路由对应的模块、未知路由默认、依赖失败与用户重试。保留全部487业务回归。

验收：页面加载字节/工作区边界由构建模块图和实际浏览器观测分别验证；全回归、Go嵌入资源、独立审查与同版发布后交付。按需JS不保证所有页面字节相等，不以改告警阈值代替优化。账号/SQLite不变，服务不自动启动，版本不变。
