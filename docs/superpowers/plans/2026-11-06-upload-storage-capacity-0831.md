# v0.8.31 上传暂存空间观察

## 产品范围

上传新批次之前可按需查看暂存路径、文件逻辑占用、文件数量、所在卷对当前进程可用空间与各自UTC。网页显示本次所选文件量；不足提示建议释放空间，不声称预留或承诺写入成功，不改接收/上传语义。仅扫描本工具暂存目录顶层有效UUID.data/.part普通文件，不递归、不统计SQLite/授权/其他文件，不跟随符号链接。逻辑大小不是物理分配/配额，接收与清理可能同时变化，统计不是原子快照。

## 后端

GET /api/uploads/storage为固定路径，沿用管理鉴权，no-store；其他方法405。目录枚举每批128检查context，单文件消失记录不完整，其他错误返回失败不编造0。磁盘探测失败单独available=null/error，不隐藏已读暂存统计。Win GetDiskFreeSpaceEx / Linux Statfs，int64溢出拒绝，未知平台不可用。数字用十进制字符串。只读临时文件测试不碰账号库。

## 前端与发布

独立UploadStorageStatus在选择区按需读取/手动刷新，选择量用现有BigInt。失败保留旧快照标历史；页面/身份/关闭旧响应失效，无轮询/写请求/自动清理。完整选择和普通选择均展示所选字节；旧批次补传不能把整个批次当本次空间需求。

先写后端计数/排除/取消/探测失败与HTTP测试并观察红，再实现；前端行为红绿、模拟桌面窄屏、独立复核及完整同版门禁。版本说明另做当前状态索引清理，历史原文保留为附录，不把真实百度/NAS未验收写成通过。
