# v0.8.31 弹窗键盘一致性

核查共享modal.ts：显式负tabindex元素进入Tab环，disabled fieldset后代未按有效禁用状态排除，Escape冒泡可能同时调用嵌套外层关闭。Tab焦点停在非循环成员时也缺明确返回点。

范围仅共享指令：过滤负tabindex与有效disabled，保留原生summary；Escape只交给当前弹窗；无可聚焦项时聚焦容器并限制Tab；失去循环成员位置时回到首/尾。卸载恢复原入口，临时容器tabindex恢复原样。业务确认、网络请求、队列策略不变。

先对真实TS指令做JSDOM定向失败复现，再修复；包含初始焦点/双向循环、嵌套Escape、fieldset、无可聚焦项、恢复入口。原页面回归与模拟浏览器分别验收，完整打包后交付；仍v0.8.31，不使用真实账号操作。
