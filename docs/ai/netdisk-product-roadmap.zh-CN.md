### 产品目标和菜单结构

产品目标是常驻运行的个人网盘管理工作台：文件管理作为主要入口，上传与监控下载作为传输方式，缓存和清理辅助整理，历史证据支持异常恢复。继续沿用Go后端与Vue前端，不再另起一套界面。

| 导航层级 | 页面与内容 | UE约束 |
|---|---|---|
| 常驻Header | Logo；网盘、传输、记录、设置；后台任务入口；账号与退出 | 执行中任务可收起并继续；不把历史状态当作当前运行状态 |

| 传输侧栏 | 下载、上传；各自总览进入批次/根任务详情 | 总览以表格组织；详情优先显示执行中、等待、完成；目录只计数，容量和速度只按实际口径统计 |
| 记录侧栏 | 入队记录、远端操作、扫描与缓存变更、恢复/迁移证据 | 从业务结果直接跳到相关记录；普通浏览不要求用户先理解审计术语 |

## 产品定位与边界

面向个人/NAS常驻使用的百度网盘管理软件：网盘文件是主要对象，上传、后台监控下载、整理、搜索、缓存、任务与证据形成完整闭环。下载仍是“选择项目→在线预检→确认移入自动监控目录→后台发现并下载”，不改成依赖百度原版客户端，也不把“下载”按钮伪装成即时浏览器下载。
继续单下载目录绑定一个账号；远端为文件事实来源，本地缓存为加速和统计辅助。远端已确认、本机观察、历史记录、正在执行、结果未知分别表达。未知写操作缺可信完成凭据时不重发、不强行放行。

| 审计 | 入队/监控/任务/操作/扫描/迁移的SQLite历史、UTC和JSON导出 | 入口较多，普通用户缺“这次操作到底发生什么”的聚合详情 | 各History/Events/OperationWorkspace |
| 账号/设置 | OAuth、首次填应用凭证、表单会话、Bearer CLI、路径迁移 | 新手权限解释、配置优先级、当前有效值与只读原因需要统一 | OAuthWorkspace.vue、PathSettingsWorkspace.vue |
| 其他网盘功能 | 尚未作为完整产品能力接入 | 分享、分享转存、回收站、媒体预览、云端空间概览需先核实官方API/应用权限 | 候选池；不能仅仿制按钮 |

“源码可用”不等同真实账号/NAS验收：继承基线的本机模拟、SQLite和构建证据与真实服务、跨重启、NAS文件占用要分别登记。

## 信息架构与布局准则

| 位置 | 固定职责 | 不放在此处的业务交互 |
|---|---|---|
| 顶部Header | Logo、传输/网盘/记录/设置、账号与退出；后续可展示真实服务状态和版本 | 不堆某目录的删除/扫描按钮，不用无依据绿灯表示任务健康 |
| 左侧模块菜单 | 当前模块稳定页面，选中和可访问名称明确 | 不混入一次性确认、危险开关或临时任务进度 |
| 页面标题/主工具栏 | 当前对象/路径，上传、新建、下载、刷新等高频操作 | 不能把主要动作藏在hover或一串普通说明文字里 |
| 表格与批量工具栏 | 名称、大小、状态/进度、时间分列；选中后显示批量动作和明确选择范围 | 不为每个文件堆大卡片，不把“选本页”等同“选全部” |
| 抽屉/二级页 | 属性、目标目录、预检、完整证据、长表单 | 高频浏览不反复弹完整审计详情 |
| 后台任务/通知区 | 上传、下载、扫描、清理的进度与回到任务链接；可收起但仍执行 | “已接收”不能显示成“已上传”，“运行中历史”不能充当活worker |
| 设置 | 账号、存储、并发、默认策略、日志保留等持久配置 | 删源策略不能藏在全局设置后无感作用于已确认任务 |

布局坚持高信息密度和足够点击面积；容量默认IEC单位、原值按需核对；日期默认本地可读时间并可查看原始UTC。危险操作不用仅颜色区分。空、加载、失败、部分结果、过时和无权限有不同文案与恢复入口。表格只在自己的容器横向滚动，Header/侧栏不能遮住聚焦项和弹窗。

## v0.8.31优先实施顺序（逐项实施，以下包含剩余规划）

### P0-A 文件管理形成完整常用工作流

1. 多选、Shift范围选择、全选当前页与已选数量；跨页选择若实现，必须有明确范围与身份快照。
2. 名称/大小/类型/时间排序、目录优先；排序条件贯穿远端分页与边界核对，不能只重排当前100项却称全目录已排序。
3. 统一目标目录选择器，支持面包屑/搜索/新建/目标预览；移动、复制、下载预检、上传复用交互但保持各自确认语义。
4. 按API能力补复制和批量移动/删除/下载预检；先预览冲突和影响，再固定清单逐项执行。默认跳过或另存，同名覆盖必须明确确认。
5. 操作后清理/更新选择，成功刷新相关目录与大小；失败或unknown停止关联项，不把整批一律显示成功。

成功标准：桌面/键盘/窄屏完成一组“选文件→选目标→核对→执行→看到正确结果”；分页/排序/迟到结果不串身份，线上身份变化会拒绝并刷新该对象。

### P0-B 传输中心与下载闭环

1. 下载入口清楚说明“移动至监控目录”；预检展示源/目标、keep/delete策略、冲突与下一步。
2. 入队记录关联云端operation、监控run和下载根任务，尚未发现时有真实等待原因与核对入口，不创建虚假下载中任务。
3. 统一任务总览/详情、处理中→等待→已完成排序、筛选和操作反馈；目录只计数，文件显示大小/进度/速度。
4. 用证据区分暂停、授权等待、空间不足、限流等待、源待核对、后处理待核对；平均速度和活跃时长继续排除离线。
5. 保留已有真实任务的未知后处理，不用界面迁移“修复”历史证据缺口。

成功标准：一次用户下载意图可追到每个阶段，重启后可从同一任务继续核对；有活跃字节/UTC证据才称恢复下载成功。

### P0-C 上传从可用到可靠易用

1. 分开显示浏览器→本机接收、哈希、百度分片、合并、线上核对；批次总量/完成/失败/待核对和逐文件进度一致。
2. 明确暂停当前项、停止后续项、取消和重试的区别；补受控并发、真实网络字节/活跃时长/速度/ETA，不把暂存字节当云端进度。
3. 核实并持久化uploadid、分片序号/MD5、已确认范围与UTC，支持可信的分片级恢复；账号核验前等待。最终提交unknown不重发。
4. 目录上传明确空目录支持条件；浏览器不提供的内容不可宣称已上传。缺本机文件时可定位并重新选择缺失项。
5. 暂存空间展示、磁盘不足提示、失败/unknown数据保留与显式回收；成功/取消/中断回收不留永久大文件，不能删除在传项。
6. 在本工具创建的隔离测试目录完成小文件、多文件、目录、大文件/断网/重启/同名冲突的真实上传验收，记录实际远端路径和身份。

成功标准：批次各项计数可核对，恢复不重复创建文件，不覆盖已有用户文件；每条“完成”有可验证的远端身份证据。

### P0-D 搜索、缓存与目录大小

1. 文件列表始终以远端为准；完整缓存优先提供快速搜索/目录统计。不完整或过时清楚说明范围和观察时间。
2. 先核实官方搜索API的范围、类型限制、分页和应用权限，再决定远端补查；不以空本地结果冒充全盘无结果，不无提示后台遍历全盘。
3. 支持目录范围、文件类型与时间等常用过滤；搜索结果可定位父目录并保持搜索条件返回。
4. 状态入口概览覆盖、当前worker、最近成功UTC、待刷新目录和失败原因；刷新中继续使用上一份已发布缓存，目录变化时才提交新清单。
5. 上传、移动、改名、删除后按受影响路径失效/刷新列表和大小；父子目录重叠时合计不伪装为精确全盘总量。

成功标准：列表/搜索/统计来源一致可解释；换目录/换条件/重启与缓存代次变化后不会展示错对象的大小和分页。

### P0-E 全站UE一致性与诊断

1. 统一主次/危险/禁用按钮、操作完成/失败/未知通知、错误恢复方式；禁用原因可见，不再静默吞点击。
2. 统一目标选择、面包屑、长路径复制、空态、骨架/加载、重试和保留旧结果提示；保留浏览器前进/后退和可分享深链。
3. 键盘Enter打开、Esc关闭、焦点回原按钮，范围选择/快捷键需与输入框编辑冲突隔离；图标有可访问名称。
4. 将普通任务详情与高级证据分层；合并旧高级页已有重叠功能，未迁移能力列清单保留，不能直接删旧入口导致功能丢失。
5. 账号状态、API权限不足、路径只读原因、.env优先级和首次配置流程给出具体可操作解释；日志按任务/批次/请求ID和路径关联，秘密信息脱敏。
6. 维护本版说明、当前构建标识和已知限制；每次同版更新可核对程序与数据是否保持分离。

成功标准：主要流程无需猜哪个文字可点、为什么不可操作或结果在哪；同类动作在不同页面行为一致，窄屏可完成关键流程。

### P0-F 验收与数据保护

验证矩阵分层：源码/单元→模拟provider→SQLite跨重启/断电窗口→桌面/窄屏/键盘→真实百度隔离目录→NAS/SMB。记录操作系统、协议/路径、UTC、源/目标身份、结果回执和真实文件。
保护现有账号/任务：同版只覆盖程序白名单；切版才移动唯一状态；更新可按用户授权结束目标进程但不杀其他服务。数据库升级先保留可恢复备份并校验，文件系统测试不以本机盘冒充SMB。
成功标准：核心真实链路有证据、未知写操作不会重放、原用户内容与设置不被测试或更新覆盖。无SMB环境时明确未验收，不伪造通过。
