# D3 油猴选中项与管理页衔接

沿用已授权的 D3：油猴只提取当前文件视图中明确选中的绝对路径，传给配置的管理页作为待核对输入；管理页仍须登录、服务端预检、明确勾选和确认。脚本不请求移动、下载链接、Cookie、Token 或管理员密码，不改变管理认证/Origin 与 unknown 隔离规则。

## 适配与传递

- 自有文件页 `/disk/home`、`/disk/main`：读取旧版 context.list.getSelected 或已知 `.wp-s-core-pan` / `.nd-main-list` / `.nd-new-main-list` Vue selectedList。只接受数组和有效 path，多来源同时可读但不一致时失败，空选择不回退整页 FILEINFO。分享/回收站/不识别页失败。页面内部 API 不是稳定公共协议，真实页面兼容独立验收。
- 适配线索来自作者发布的[网盘直链下载助手源码](https://openuserjs.org/scripts/syhyz1990/%E7%BD%91%E7%9B%98%E7%9B%B4%E9%93%BE%E4%B8%8B%E8%BD%BD%E5%8A%A9%E6%89%8B/source)，只参考选中列表结构，自行实现提取和校验，不复制下载、Cookie 或 RPC 逻辑。
- 油猴沙箱使用 unsafeWindow 只读页面选择；GM 存储仅保存管理地址，默认 http://127.0.0.1:18089。允许本机 HTTP 或远端 HTTPS；拒绝用户名密码、查询、fragment 和其他路径。不以百度页面 localStorage 保存设置。
- 用户点击按钮时列出目标管理地址与路径，确认后使用 GM_openInTab 打开 `/intake#nas-intake=<编码 JSON>`，不使用 opener/message 跨站通道。载荷只含 version=1 和 paths，不含身份/策略/凭证。限制 1..20、单路径 2048 字符、编码载荷 60000 字符。
- 管理页在任何网络请求前解析和清除该 fragment；只填 textarea 并提示核对当前授权账号/源路径，不自动预检或移动。不合法载荷明确报错，原有手工入队仍可用；修改输入继续使预检失效。
