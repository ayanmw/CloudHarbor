# 阶段 D：入队与任务管理体验

目标：无需手写任务 API 即可管理后台下载；从明确选定的网盘项目发起服务端入队，补齐原油猴脚本尚未实现的能力。沿用已授权的持续实施和独立测试版交付范围，不操作真实百度账号。

## 当前源码证据

- 原 `tampermonkey_baidupan_nas_queue.user.js` 仅打印 window.yunData.FILEINFO；其自身注释说明这不一定是选中项，没有实际移动请求，不能据按钮名称认定入队已实现。
- 已有管理认证覆盖所有页面/API/WS，并拒绝跨 Origin 请求。不能为方便油猴调用而放开管理入口来源，也不能将管理员密码、百度 Token 放进网页 URL 或第三方页面。
- 下载器取消/重试 API 已有认证、状态和源扫描校验；取消成功不代表 active worker 已排空。任务策略固定在入队时，与默认模式分离。
- Go fs_id 为 int64；浏览器 Number 对大于 2^53 的 ID 可能失真。界面操作必须使用精确十进制 task_id 字符串，不从旧数值字段拼 URL。

## D1：已有任务操作（已实现，待纳入下个独立测试版）

- [x] HTTP/WS 输出字符串 task_id 与服务端 can_cancel/can_retry；快照判断认证、扫描资格、worker 活跃状态、停止/存储错误。
- [x] 两种任务页面提供立即扫描、根任务取消/重试；反馈 401/404/409，按任务去重提交。服务端仍在执行时重新校验条件。
- [x] 显示每个根任务的固定后处理策略、启动次数、下次尝试时间；子项不提供独立根任务操作。
- [x] 大整数 ID、取消尚未排空/恢复、过期认证能力、Node 前端执行和实际 HTTP/WS 字符串字段回归测试。
- [x] 最终两平台全模块 race/vet、独立 review 和源码检查点；真实浏览器视觉/点击和新包验收尚待进行，当前可用独立包仍为 v0.3.0-preview.1。

## D2：服务端入队（未实现）

沿用项目原意，将用户明确选择的云端项目移动到配置的 QUEUE_DIR，页面必须提前展示源路径、目标目录及移动后语义，用户点击后才提交。目标目录固定使用服务端配置，冲突失败，不覆盖、不自动改名。下载完成仍依各根任务固定 keep/delete 策略处理。

- [ ] 实现受管理认证保护的列表/预检/提交入口；输入不接受下载链接、任意目标目录或客户端提供的 Token。
- [ ] 严格绝对云路径与项目标识校验；拒绝根目录、队列本身、队列祖先/内部项目以及同批父子/同名目标等歧义输入；返回逐项结果。
- [ ] 官方 API 移动请求使用无覆盖策略；不能把全局 errno=0 当作所有子项成功，不能把异步受理当作完成。
- [ ] 请求中断或回复丢失时保持结果未知并要求重新核对源/目标，不自动重发移动；入队与扫描/下载的竞争要有明确串行边界，失败不触发误删除。
- [ ] 限制批量规模和请求长度，按账号认证状态执行，凭证切换后旧预检不可直接提交。
- [ ] 真正的 API/磁盘测试覆盖冲突、部分失败、迟到回复、队列边界、重试与同一请求重复提交。

依据：仓库内旧 SDK `doc/baidu-go-sdk/openxpanapi/api_filemanager.go`；本轮另核对[百度官方 Go SDK 文件管理模型](https://github.com/baidu-netdisk/baidu-drive-sdk-go/blob/main/baidudriver/api/file_manager.go)，其声明 copy/move 项 path/dest/newname、ondup 策略和单项结果；没有把 SDK 声明等同于真实账号执行成功。百度文档页本轮无法直接读取，实施时以可读取的官方代码及本地契约测试为依据，真实调用独立验收。

## D3：油猴与管理页衔接（未实现）

- [ ] 独立选中项适配层，不将整页 FILEINFO 当选中项；页面结构或数据身份无法可靠确认时明确失败。
- [ ] 只向用户配置的管理页传递待核对的项目标识/路径；由管理页登录并预检后提交，不在百度页面保存或索取管理员/百度凭证，不自动执行跨站云端修改。
- [ ] 用户可在管理页直接选择或输入项目；油猴仅是明确选中数据的入口，不能作为数据真实性权威。
- [ ] 代表性 DOM/数据夹具、未选中/多选/不可识别页面回归与实际百度网页适配分开记录，未实测不能宣称全部页面支持。
