# 下载可靠性与持续优化设计

目标：不依赖百度原版客户端，在 NAS 后台持续下载；故障可恢复，周期性交付独立测试版本。

## 路线与边界

1. v0.1.0-preview.1：下载正确性。保留 Go/xpan、嵌入式 WebUI。统一配置；严格验证续传；临时文件与本地 SHA256 完成凭据；父目录汇总失败；网盘后处理失败可重试；并发状态快照。交付 Windows、Linux AMD64/ARM64 独立包。
2. 下一阶段：持久化队列、限并发、取消、分类重试、优雅退出。分页扫描提前到首版，避免目录清理遗漏第 1001 项。
3. 随后：OAuth 应用/保存/自动续期、管理认证、健康检查、NAS 权限。
4. 最后：服务端路径入队、油猴脚本、任务操作与界面完善。

各版本均需自动化故障测试与独立发布说明。真实百度账号及 NAS 验收结果与本地测试分开记录。当前授权包含按上述路线实施与本地交付，不包含发布外网、推送或操作真实网盘。

## 第一版不变量

- LOCAL_DOWNLOAD_DIR 为规范变量；兼容旧 LOCAL_DOWN_DIR，规范值优先。
- 非零偏移仅接受起点匹配、范围合法的 206；200 表示不支持本次续传，重新从零下载。错误响应不修改已有临时文件。
- 云端 MD5 语义未验证，不用于普通 MD5 比对。长度不足/超长、写入/关闭失败都不能成功或修改源文件。
- 临时文件及版本元信息保存在下载根目录的 .nas-downloader 下。绑定 fs_id、size、mtime、云端 MD5、本地相对路径；不信任历史裸残缺文件。
- 完成后保存本地 SHA256 凭据；复用已有文件必须元信息与本地内容一致。无可信凭据的已存在文件保留并报告冲突，不覆盖。
- 目录子任务全部成功后才对顶层目录执行下载后处理；子项不逐一改名，避免失败重试时云端路径漂移。keep 标记顶层项目，delete 删除顶层项目。旧标记子项不能证明本地副本存在，阻止父目录后处理。
- 后处理失败显示失败，下一轮通过完成凭据复用本地文件后重试。此版本依赖目录扫描驱动重试，尚无独立重试队列。
- 不允许远端路径向配置下载根目录之外写入，不允许远端文件覆盖内部状态目录；拒绝根目录内目标路径中的符号链接。配置根目录及其上级的符号链接视为用户指定的存储位置；不防范其他本地进程并发替换目录。
- 文件优先通过同卷硬链接无覆盖发布；若硬链接不受支持，则复制到目标目录中的临时文件，临时文件名先写入任务部分文件记录，复制后按已确认 SHA256 和长度复核，再以平台 no-replace 原子重命名发布。回退需要额外一个文件大小的空间与复制 I/O；Linux 文件系统还需支持 `renameat2(RENAME_NOREPLACE)`，Windows 使用目标必须不存在的 `MoveFile`。重启只清理部分文件记录明确指向的临时 sibling，不扫描或删除其他文件。Linux 会在状态文件原子替换、关键目录创建和最终文件发布后同步父目录，使 sending 日志先于网盘源操作持久化。若目录同步或 no-replace 发布失败，该步骤失败并停止相应源操作。NAS/文件系统必须实际履行同步和原子重命名请求；本地测试不能证明设备缓存、突然断电或存储控制器的掉电持久性。
- 第一版只处理静止的云端队列副本。下载期间远端增删改、按路径后处理的身份竞争留待后续版本补强，不据本地凭据声称锁定远端身份。
- 独立程序默认监听 127.0.0.1；容器内部监听 0.0.0.0，宿主端口仅发布到 127.0.0.1。管理认证尚未实现。

## 验证

本地 HTTP 服务器模拟百度 API 与文件流，实际执行下载器和磁盘写入。覆盖 Range 忽略/错误、短流、断流续传、已有文件冲突、子项失败与恢复、源文件处理失败、路径与状态快照。执行 go test ./...、go vet ./...、构建与发布包冒烟；有可用工具链时执行 race。
