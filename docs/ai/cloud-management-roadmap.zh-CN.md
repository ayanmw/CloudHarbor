## 目标

从网页管理本地下载路径与百度网盘内容，并用可恢复的全盘缓存支持目录大小统计、重复内容清理和空目录清理。所有网盘写操作都需要重新核验对象身份；结果不确定时隔离并保留证据，不自动重发。

详细设计与接口边界见 [网盘管理与本地目录缓存设计](../superpowers/specs/2026-10-29-cloud-management-cache.zh-CN.md)，按文件拆分的实现记录见 [实施计划](../superpowers/plans/2026-10-29-cloud-management-cache.md)。

## 阶段与验收

### 1. 本地路径设置与迁移（源码已实现）

- 查看自动监控目录和本地下载目录；默认下载目录为程序工作目录下的 `downloads`。
- 网页设置持久化并立即生效；`.env`/进程环境显式配置优先且网页只读。下载任务运行或维护期间拒绝变更。
- 可选迁移下载目录内容；复制后逐文件校验，冲突或占用时保留源数据，只有完整核验后才移除旧目录。阶段、进度和错误写入 SQLite，重启可恢复。
- 验收：路径设置跨重启读回；运行任务时拒绝修改；迁移成功、冲突、中断恢复均保留正确数据。

### 2. 网盘目录浏览和远端管理（源码已实现）

- 分页浏览、路径导航、新建目录、移动、重命名和删除；不支持上传。
- 手动选择的网盘项目移动到自动监控目录，由现有扫描器接手下载。
- 远端变更前暂停领取并等待活动任务；变更后复核并重建待执行队列。变更失败或结果未知时显示状态并隔离相关项目。
- 验收：API mock 覆盖成功、身份变化、冲突和未知结果；实际百度账号操作仍需独立验证。

### 3. 全盘列表缓存和目录大小（源码已实现）

- SQLite 按账号隔离缓存文件/目录及云端观测时间；后台低频分页扫描、节流、退避、续跑和重启恢复。目录大小聚合结果按账号和路径持久化，扫描页提交/远端缓存失效后由代次机制使旧结果失效，重启后仍可复用有效结果。
- 浏览在扫描期间保持可用。目录大小来自本地全盘缓存，展示覆盖完整性、网盘观测时间和本地计算时间；首次或失效后本地重算，同代次刷新直接读取结果。远端操作后失效对应账号缓存。
- 目录列表使用完整本地聚合值展示每个目录大小；聚合覆盖未完整时显示“缓存大小未完成”，不把百度 API 对目录返回的占位 `0 B` 伪装成真实大小。
- 列表聚合大小与百度对象原始 `provider_size` 分开传递；远端改名、移动和删除仍使用原始对象大小参与身份复核。
- 验收：分页/重启/部分覆盖和 SQLite 事务回滚回归；大型 NAS 上的扫描速度与百度限流仍需实测。

### 4. 重复内容和空目录清理（源码已实现）
