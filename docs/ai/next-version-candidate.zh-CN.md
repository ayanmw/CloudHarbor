# 下一版候选目标：本站文件库基础（待用户确认）

本文件为 v0.8.32 收尾时准备的候选，不是切版或开发授权，不预先建立版本标签。

目标：在泊云中选择一个明确本地目录作为本站文件库，用户能在网页浏览、搜索基础文件信息、下载文件；不依赖百度授权。限制为单用户、一个文件库，优先完成可真实体验和验收的闭环。设备目录权限保留边界，不提前开发多用户、公开分享或完整 Client。

建议成果：
1. 上游可配置文件库根目录，拒绝凭据目录、越界路径和链接逃逸；不迁移或删除已有下载。
2. 网页独立“本站文件”入口、路径导航、紧凑文件表格、大小与时间；和百度文件来源明确分开。
3. 受控下载支持范围读取和内容版本检查；读取失败与根目录离线有明确提示。
4. SQLite记录文件库身份和索引观察，扫描失败保留旧观察但标记过期，不推导删除。
5. 固定范围验收：无百度凭据、中文路径、大文件读取中断、越界拒绝、文件被外部修改、目录离线与服务重启。

复用选择先做限时小验证，合适则使用成熟组件；不建设通用框架。文件库上传／写管理、设备 token＋Client、删除传播各自后续闭环，不在本批中假装已完成；最终下一版范围由用户审阅确认。

完成标准：上述用户旅程、失败路径及界面可实际验收，打包门禁通过；完成最终tag和GitHub Release，再提出下一版目标。独立NAS/SMB验收需真实环境，不能以本机磁盘替代。每个后续goal只覆盖一个已确认闭环和其发布收尾，不设置无限持续推进目标。
