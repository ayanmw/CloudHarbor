# 认证与管理入口 Implementation Plan

**Goal:** 实现阶段 C，交付授权可应用、可保存续期且管理入口受保护的版本。

**Spec:** [auth-design.md](auth-design.md)。用户已授权持续实施；当前会话测试先行、inline 执行，交付前独立审查。

## Task 1：可取消且脱敏的 OAuth/账号 API

- [x] 增加 Context 版本，保留现有命令行调用兼容；校验响应、限制参数与重定向。
- [x] transport 故障测试先观察失败，再实现实际请求取消、错误分类、slow_down；pending 分支保留，完整设备授权等待与主程序集成尚待验证。
- [x] 百度 uinfo 校验与认证错误识别。

## Task 2：凭证管理与队列集成

- [x] 私有凭证/账号绑定原子记录，启动恢复优先级。
- [x] 核心模块：串行应用/刷新、轮换先保存、验证账号、自动续期/退避；主程序调用尚待集成。
- [ ] 下载器认证门禁与 auth_wait 恢复，不把认证失败当下载失败预算。

## Task 3：管理保护与前端

- [ ] 管理 Basic/Bearer、私有随机默认密钥、Origin/WS 校验。
- [ ] 网页授权实际应用，服务端设备会话，认证状态与扫码界面不泄漏凭证。
- [ ] 健康状态独立反映认证和扫描结果，文本渲染修正。

## Task 4：验证与交付

- [ ] 定向/全量 test、vet、Windows/WSL race、独立 review。
- [ ] 更新启动/容器配置、测试说明，独立版本与哈希及实机边界。
